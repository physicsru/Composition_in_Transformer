# 只用 w2 / d2 数据学习可重复组合：下一轮实验

日期：2026-09-16。状态：实验提案，尚未运行。本文件保存在本地；基于 Miyabi 的 N0–N3、X 系列文档、代码和指标快照。

## 1. 研究目标与计数口径

目标是：只用浅层 w2 / d2 任务，通过 next-token prediction（NTP）或 RL，学会把已知关系组合成未见过的链，并把同一计算推广到更大的深度。

暂定允许模型输出中间实体 CoT。记关系数为 R、实体数为 E、原子事实数为 F=ER，每个关系是 E 个实体上的随机置换。若用户的 n 指关系数，则固定 E 后考察 O(R) / O(R²)；若 n 指原子事实数，下面的首选方案直接是 O(F)。同时报告 E 和 R，不把 E 隐藏在常数中。

约束覆盖全部训练历史：预训练、监督微调、RL 和自训练都只使用 w2 / d2 问题。w2 本来就包含两个独立的原子子任务，允许其原子答案监督，但不增加独立 width-1 / atomic 训练行。不使用 d≥3 训练问题、长链奖励或长链伪标签。

分开记录：唯一问题数、唯一原子事实数、监督答案/过程 token 数、重复呈现次数、优化步数、RL rollout 数和 verifier 调用数。O(R) 个问题不代表 O(R) 总算力。

“d∞”指任意有限深度的可重复执行，允许推理资源随深度增长。有限长度准确率曲线只能提供经验支持；无界结论需要额外的归纳证明。

## 2. 现有结果怎样决定实验优先级

依据：[N0–N3 审阅](results_review_N0_N3_2026-09-16.md)、[原始回应文档快照](evidence/miyabi_N0_N3_2026-09-16/toy_model/docs/experiments_N0_N3.md)、[X 数据审计](evidence/miyabi_N0_N3_2026-09-16/x_audit_summary.md)。

- X 的固定 w2 配方已经产生很高的 d2 新实例/新关系对泛化，而 d3 仍接近机会水平。下一步应直接检验“逐步输出状态能否使浅层学到的更新被重复使用”。
- N1 固定角色事实覆盖和总曝光后，更多伙伴仍显著改善迁移。因此第一轮给每个关系少量但多样的前后伙伴，避免单一伙伴成为捷径。
- N2 显示两角色训练与角色未覆盖事实迁移之间存在复杂干扰。第一轮先让每个事实在两角色都覆盖，把未覆盖事实压力测试留作独立实验。
- X / F / N1 / N2 旧 checkpoint 包含独立原子行或 width-1 数据，不能充当严格新目标的主实验初始化。它们是已有证据，新主实验从头训练。

第一轮因此回答：**在全部基本状态更新都已得到浅层覆盖时，哪种输出协议能学会新组合和重复执行？** 原先 H 技能完全不参与组合的更强任务保留为后续独立检验。

## 3. 首选线性数据集 L

首轮沿用 E=500、R=20、world seed=42；模型 seeds=1/7/123。世界、关系图、w2 配对、验证题、测试题和采样顺序使用独立随机流。

### 3.1 w2：40,000 行，完整原子覆盖

F=10,000 个事实，每个事实恰出现 8 次：第一槽 4 次、第二槽 4 次；每次换伙伴，禁止重复行和同事实自配对。每行包含两个独立任务，因此共 8F/2=40,000 行。

可用 4 组事实上的有向置换配对实现：每个事实每组各出现在第一、第二槽一次。实际生成后检查槽位、曝光次数、伙伴数及重复行，不仅检查配置。

### 3.2 d2：40,000 行，稀疏关系配对

构造 R 个关系上的有向图，每个关系恰有 k=4 个出邻居和 4 个入邻居；图强连通，边均不重复。每条边 (r,s) 表示允许训练 r 后接 s。对每条边覆盖全部 E 个起点。

训练关系对数 kR=80；d2 行数 kRE=40,000。由于关系是置换，每条边覆盖所有起点也就覆盖所有 bridge。因此每个原子事实在第一、第二角色分别有 k 个伙伴和 k 次曝光。

R²=400 个有序关系对中，80 个用于训练，320 个未用于梯度训练。这个设计不保留整种技能；保留的是组合方式。

### 3.3 数据预算与验证预算

| 数据 | 公式 | E=500，R=20 |
| --- | ---: | ---: |
| w2 训练行 | 4ER | 40,000 |
| d2 训练行 | 4ER | 40,000 |
| 训练合计 | 8ER | 80,000 |
| d2 验证 | R 个额外关系对，每对 50 个起点 | 1,000 |
| w2 验证 | R 个新配对行 | 20 |

验证关系对从未训练的 320 对中抽出 20 对，构成与训练边不相交的有向 1 正则图：每关系各 1 个入伙伴、1 个出伙伴。其余 300 对构成最终 d2 新对测试池。验证标签也计入模型选择的数据预算。小 w2 验证集仅辅助选择，另穷举已知 F 个原子转移作能力诊断；穷举不引入新的原子标签。

所有输出臂共用相同的问题 ID、世界、训练图和测试题，先冻结题目再渲染字符串。完整训练行和验证标签预算仍为 O(ER)，固定 E 时为 O(R)。最终测试标签只用于评价，不用于选择 checkpoint；因测试反馈修改方案后，必须用新的确认世界/划分评价新方案。

## 4. 第一批：三种 NTP 输出协议 × 三个 seed

用 b=r(x)、y=s(b) 表示同一个 d2 问题。三臂使用同一 prompt：

```text
Q x r s ANS
```

| 臂 | d2 目标输出 | 要检验的能力 |
| --- | --- | --- |
| A：最终答案 | y END | 现有隐式组合路线在严格数据约束下的基线 |
| B：实体 CoT | b y END | 离散中间状态能否成为可重复使用的接口 |
| C：关系＋实体 CoT | x r b s y END | 显式生成当前操作，能否帮助对齐状态与下一关系 |

例如已知 r16(0)=196、r3(196)=96，C 输出 `e0 r16 e196 r3 e96 END`。这只是示例；训练实际使用新冻结图中的允许关系对。

测试 d 步时，B 应生成 b1…bd；C 应生成 x r1 b1…rd bd。关系、实体和停止 token 都由模型自主生成；外部程序不逐步提供正确关系或 bridge。C 比 B 多复制监督和推理 token，第一轮比较的是完整方案，不能把差异全部归因于“显式关系”这一单一机制。

### 4.1 w2 也使用相同的问答边界

一条 w2 行序列化为两个独立问答段：

```text
Q x r ANS response_1 END Q z s ANS response_2 END
```

A/B 的单步 response 为答案实体；C 为 `输入实体 关系 答案实体`。行内采用普通因果注意力，不重置历史；只在两段输出上计算损失。每个训练行仍是 w2，没有拆成两个独立训练行。

这样既包含一步问答子段，也包含两步组合问答，避免所有 CoT 样本都恰好生成两步。它只减少“固定做两步”的捷径，并不保证停止规则能外推。推理时自然 EOS 是主结果，强制输出指定步数只能作为停止错误诊断。

### 4.2 训练日程与对齐

首轮共 9 条完整训练轨迹，每臂 3 个 seed；同 seed 的各臂从相同随机参数开始，各自训练以下课程：

1. 只用上述 w2，50k updates。
2. w2 / d2 各 128 行组成 batch256，200k updates。

这是预注册的起始算力预算，不是保证收敛的理论阈值。若混合阶段末五次评估中，三种格式各自三 seed 的平均训练 d2 最终答案准确率均低于 99%，则三种格式统一延长混合阶段到 400k；是否延长只依据这一 d≤2 条件，并预先写入配置。完整保留所有轨迹；达到拟合阈值也不代表已经达到泛化极限。

沿用现有骨干：2 层、d_model=256、2 heads、RoPE base=100、untied embeddings、dropout=0、AdamW lr=3e-4、weight decay=0.1。保持各臂参数量及词表相同；增加共用 Q/ANS/END/PAD，max_len=512。先不同时扫描深度、RoPE、学习率和奖励。

分别记录最终答案 CE、中间实体 CE、复制 CE 和 END CE。建议每个 d2 问题的损失为：

```text
CE_final + CE_bridge（若有）+ mean(CE_copy)（若有）+ CE_END
```

w2 每行是两个子问答损失的均值。这样各臂最终答案权重一致；过程监督仍是额外训练信号，必须在预算中列出。不得用全部目标 token 的不同分母默默改变最终答案权重。

相同逻辑数据流按稳定名称分配 RNG，禁止依赖 active 通道序号；各臂同一步看相同的问题 ID。报告实际 token 数和算力，不能把相同更新数称为相同 FLOPs。

主要 checkpoint 按 d≤2 验证最终答案准确率选择，平手用验证 loss；同时报告预定尾五点和完整曲线。禁止使用当前覆盖全部测试类型的 best.pt 选择逻辑。

## 5. 测试矩阵：把新组合和重复执行分开观察

初测 d=2,3,4,8,16,32；方案冻结后在 d=64,128 以及新世界确认。每个非空单元建议固定 5,000 个测试问题，控制起点和各关系边际分布，保存 manifest。

| 测试链类别 | 构造 | 主要用途 |
| --- | --- | --- |
| 全部邻接已见 | 每个相邻关系对均属于训练图 | 测重复执行与长上下文，不增加局部新关系对 |
| 恰一个新邻接 | 恰一个相邻关系对未训练，位置均衡 | 在不同深度下测一个新组合的代价 |
| 随机链 | 从关系集合抽取，允许多个新邻接 | 测自然分布下的复杂新组合 |

d2 的“全部邻接已见”是训练题拟合检查：所有起点已训练，不能叫新实例泛化。d≥3 即使所有邻接已见，整个链仍是新问题。“恰一个新邻接”指恰一个邻接位置来自最终测试对池，其余位置均为训练边。最终新邻接测试不使用验证关系对；随机链也在排除验证边后采样，因此须标为这一条件分布。在可实现的条件下统一边际分布，记录采样约束。

包含重复关系、重复实体和回环。只测试每步状态唯一的链可能把“根据历史找最近状态”变成额外捷径。

### 必须报告的读数

- 自主 rollout 最终答案准确率：不给正确历史答案，使用 greedy decoding；未停止、提前停止、非法输出计为失败。
- 完整轨迹准确率：每个关系、状态和停止位置均正确，防止错误过程偶然得到正确尾实体。
- 首次错误的位置与类型：关系选取/复制错、状态更新错、提前 END。
- 状态更新相对于模型自己的上一状态是否正确，以及相对于标准轨迹是否正确；两者分开，避免把早期错误造成的后续偏离全算成新计算错误。
- 穷举 F 个原子转移的准确率；另测新伙伴 w2 自主回答。
- teacher-forcing 指标单列作诊断，不与 rollout 混用。

建议经验目标：三个 seed 在最终 d2 新关系对及 d=3…32 三类链上均达到至少 95% 最终答案准确率，再做 64/128 和新世界确认。完整轨迹、停止率、每步误差曲线必须一并报告；95% 是操作门槛，不是理论定理。

## 6. 根据结果选择第二批

| 第一批结果 | 下一步 |
| --- | --- |
| 原子 / w2 仍未掌握 | 先修复基本事实学习、格式或曝光；不把失败归因于深链 |
| B/C 的新 d2 也失败 | 检查两角色覆盖、损失、伙伴多样性；随后试平方数据预算 |
| 新 d2 高，全部已见邻接长链低 | 优先分析停止、关系读取和状态重复使用；执行外部逐步调用诊断 |
| 全已见邻接高，含新邻接低 | 聚焦组合依赖；增加每关系伙伴数及检验上下文记忆 |
| B/C 长链成功 | 冻结配方，做技能数 scaling、新世界及完整 H 留出；再拆分 CoT 机制 |

### 6.1 无需新训练的外部逐步调用诊断

对同一个严格训练模型，外部程序每步只把当前预测实体与下一关系组成它熟悉的原子子问答前缀，取得下一实体，再递归调用。它可以识别原子更新是否足够准确。

如果这种调用长链成功而自主 CoT 失败，说明模型事实知识在规范输入下可用，下一步应研究自主控制与历史表示。外部程序提供了关系选择、循环和状态格式，因此该结果不能计作自主 Transformer 达成目标。

若错误分解显示关系读取随距离显著恶化，可在最好的输出协议上增加一个 NoPE（不使用位置编码）对照，保持数据、层数和日程一致，检验当前 RoPE 位置外推的影响。它是诊断驱动的第二批实验；去掉 RoPE 本身不保证学会顺序控制。

必要时再做共享权重 recurrent cell 或固定局部窗口的结构化执行器，明确区分“训练学会转移”与“架构提供循环”。这可能是达成实用目标的方法，但不能写成普通 Transformer 自发学会了循环控制。

### 6.2 伙伴数与平方预算：按需进行

先对最好的协议试 k=1/2/4/8，保持每事实每角色总曝光相同；例如固定总曝光 8，边上实例重复 8/k 次，按唯一题数与重复次数分别计数。它检验伙伴多样性的作用，不再混入剂量增长。

若稀疏图配方不足，再用约 80% 的 R² 有序关系对，每对全部 E 起点；保留约 20% 的关系对作验证与最终测试。d2 训练量约 0.8ER²，在 R20/E500 时约 160k 行；w2 仍为 40k。不要把全部关系对训练后再把长链成功叫作新关系对泛化。

### 6.3 保留原问题的 H 技能检验

从头重建 T=12 / H=8 的版本：全部 20 个关系均出现在 w2，d2 只使用 T 上的稀疏关系图。固定验证 H 与最终测试 H 的使用规则，报告 TH / HT / HH 以及混合 H 长链、纯 H 长链。

这一版本检验“只在原子子任务学过的技能能否进入组合”。不能用第 3 节全部关系都参与 d2 的成功替代它。再进一步才加入 400/100 的角色事实 S/U 留出，以连接原有 N1/N2 机制问题。

### 6.4 RL 放在第二阶段，保留严格浅层约束

对出现有用但未饱和的 d2 策略的协议，在仅依据 d≤2 指标选定的同一 checkpoint 分支：

1. 继续 NTP，作为训练延长对照。
2. 在完全相同的 w2/d2 问题池做 on-policy RL，奖励格式有效且最终答案正确；w2 对两个子问答取平均奖励。

若要奖励 bridge 正确，另标为过程奖励臂，它改变监督信息，不能与纯最终答案奖励混称。记录 rollout、有效监督 token、verifier 调用、KL、熵和训练正确率；按主要算力预算配对，同时披露更新数差异。

RL 不加入 d≥3 prompt，也不把长链测试结果用于奖励或 checkpoint 选择。主测试仍用一次 greedy rollout，不用 best-of-N 改变推理预算。

若模型在所有训练 d2 上奖励已饱和，最终答案 RL 未必还有有效信号，且浅层奖励无法区分任意两个浅层行为相同、深层行为不同的策略。因此 RL 值得作为优化选择实验，不能预设它会自动发明循环；从随机初始化直接 RL 也不列作第一批。

## 7. 何时可以谈 O(n) 与 d∞ 理论

### 7.1 数据 scaling

成功配方冻结后，在 E=500、R=10/20/40 下使用相同 c=8、k=4 重训；每问题重复预算与学习率规则固定，报告总更新和算力。训练数据分别为 40k / 80k / 160k 行。随后另扫 E，检查结论是否依赖固定实体规模。固定模型的规模实验同时检查原子记忆是否饱和；若大 R 已经无法拟合原子表，应独立做预先声明的容量对照，不能直接认定是组合所需数据阶数增加。

至少在新 world seeds 43/44 和新图划分重复主要结果。数据规模的公式本身是线性的，但“模型用该线性预算稳定学会目标”需要跨规模实验，不能从单个 R20 的成功推出。

### 7.2 最值得证明的条件命题

设共享更新器 U 只接收规范化的离散状态 x 和关系 r。若所有 ER 个输入都满足 U(x,r)=f_r(x)，且执行器每步读取正确关系、将输出重新作为同种状态输入、只在指令结束时停止，那么归纳可得任意有限 d：

```text
x_0 = x
x_(t+1) = U(x_t, r_(t+1))
x_d = f_(r_d) ○ ... ○ f_(r_1)(x)
```

此时穷举有限原子表可以验证 U 的正确性，循环不变量提供深度结论。普通全历史 CoT 的输入还依赖历史和位置，穷举 ER 个原子前缀并不能自动验证它所有深层上下文。

若每步在此前尚未失败条件下的总出错概率至多 ε，则由并合界，长度 d 的失败概率至多 min(1,dε)，无需独立性。这里 ε 必须包括状态更新、关系读取和停止控制；平均原子准确率不能直接代入这一统一上界。

这给出理论分析的三个对象：原子转移如何学准、离散状态如何实现可复用接口、指令选择与停止为何对步数稳定。N0–N3 主要帮助前两项；第三项是新方案必须直接测量的内容。

### 7.3 文献给出的启发与边界

[Huang et al., Transformers Provably Learn Chain-of-Thought Reasoning with Length Generalization](https://arxiv.org/abs/2511.07378) 将外推与任务代数结构、注意力检索稳定性联系起来。其特殊任务、表示和优化假设不能直接移植为当前随机置换 / 普通 RoPE 模型的保证；其递归长链自训练也不满足本项目的严格浅层约束。可借鉴的是把状态更新与关系/状态检索分开分析。

[Zhang et al., Finite State Automata Inside Transformers with Chain-of-Thought](https://arxiv.org/abs/2502.20129) 提供状态追踪与内部自动机的机制研究思路。内部能区分状态是有用证据，仍需本实验的自主长链行为和控制不变量，才能支持我们的目标。

## 8. 实现前必须完成的最小改动

1. 新数据生成器只产 w2/d2；禁用 `always_singles` 和 leftover 单行。对实际样本逐行审计，不只看 cell 参数。
2. 显式保存 `prompt_ids / completion_ids / loss_mask / action_mask`。旧“非实体后的实体是答案”规则会漏掉连续输出的中间实体。
3. 不原样复用 N2 `FixedStreams`：它主动合成 standalone atomics，且假定短输入和单答案。
4. 新增 free rollout；旧 ACC / SEQ_ACC 都基于 teacher forcing，不能评价生成 CoT。w2 第二问也需使用模型第一问输出形成历史。
5. 同步修改 max_len、因果 mask 和实际 forward 限制；仅扩大 RoPE cache 不够。先用完整前缀重算即可，不必先优化 KV cache。
6. 保存 optimizer / scheduler / RNG / 数据流游标，支持精确续训和 RL 分支；旧 `init_from` 不等于恢复训练状态。
7. 短 smoke 检查：允许格式与深度、覆盖及哈希、损失掩码、因果性、停止错误计分、最长长度、resume 一致性、微小批量的 CE/RL 梯度。

## 9. 建议执行顺序

先实现严格数据与自主评估 → 运行三格式 × 三 seed → 用错误分解选择下一步 → 成功后做 R scaling / 新世界 / H 留出；RL 和平方预算按结果分支。

**首要假说：用 w2 学到规范的单步状态更新，用少量 d2 伙伴练习把更新接起来，再通过自主 CoT 重复使用同一更新。首要反证：d2 很好而第三步就错，且错误集中在读取下一关系、停止或状态接口。**
