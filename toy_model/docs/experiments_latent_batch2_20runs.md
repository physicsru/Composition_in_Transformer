# 第五批方案：从 w2/d2 学会自主 latent 组合执行（20 runs）

日期：2026-09-18。状态：**实验设计，尚未实现、尚未提交作业**。

用户确认本轮交付为“把20个实验的方案写到服务器文档”。本文的20指20次独立完整训练，不是20种设置再各乘3个seed。六个条件全部可独立初始化、一次性排队；没有“先看深测试挑赢家，再训练其他臂”的依赖。

前序：[第四批结果](results_loop_batch_2026-09-18.md)、[第四批方案](experiments_loop_next.md)、[规范记录](WALKTHROUGH.md)。机器可读计划：[20-run manifest](latent_batch2_20runs_manifest.json)。清单是设计记录，不是现有训练器可直接执行的配置。

## 0. 研究目标与成功边界

> 仅用 w2/d2 来源题，通过 next-token prediction 或明确标注的浅题辅助监督，让 loop Transformer 在 latent space 中学会读取完整程序、组合原子关系、更新内部状态；测试时通过额外内部计算处理未训练的深组合。

本批以NTP为主，不加入RL。主假说对应**仅最终答案NTP的A条件**。辅助监督条件用于定位失败原因，不能与A混称为“纯NTP自发发现执行规则”。

### 必须遵守

1. 每道组合题一次性提供完整起点和全部关系列表；每轮只能接收模型自己的latent状态和同一份完整输入记忆。
2. 不由外部提供当前HEAD，不执行外部`pointer += 1`，不按loop编号挑选下一关系，不把gold实体或gold注意力写入前向状态。
3. 训练中所有语义程序深度最多2；不训练d3+答案、不使用长链自蒸馏/组合一致性训练来隐式引入深任务。
4. 给模型计算预算T是允许的；预算不包含正确读取顺序。主评估对所有深度采用相同T，不依赖`T=d`。
5. A没有“一轮必须等于一个关系更新”的要求；允许模型学到串行、并行或其他算法。
6. O/L只保留为已有诊断，**不计为本批自主执行成功**。

本批测有限深度到128。高分不能直接宣称d∞：有限上下文、有限测试和latent状态域都需要进一步分析。本批也不把decoder输出END解释成模型已经学会自主决定latent循环何时停止。

## 1. 为什么这样设计

### 1.1 已有证据

- L/L-w2通过固定世界的全部10,500个局部输入检查，并在d128正确；这说明原子映射可学准，并不证明完整程序执行可自主学出。
- 当前R确实是共享参数的latent recurrence，形式为`H[t+1]=B(H[t])`；答案监督下d2新对约0.2%，深组合未成功。
- RC增加显式关系/实体CoT，d2新对约100%，d3起完整轨迹为0。
- L-history已被提供正确HEAD，仍会在正确前两步之后算错第三步实体。原子能力在规范输入上正确，不保证在另一种内部状态或上下文中可复用。

因此值得直接检验：把**可反复访问的题目记忆**和**持续更新的思考状态**分开，是否更容易学到可复用的内部计算；若仍失败，是中间状态学习还是关系寻址更需要训练信号？

这里不是说“之前R不算latent thinking”。之前的负结果真实成立；新架构是下一项可证伪尝试，成功没有保证。

### 1.2 六条件的逻辑

- A/B/C/D构成“实体状态辅助监督 × 读取位置辅助监督”的完整2×2设计。
- E与A参数完全相同，只执行一轮，检验多轮计算带来的增益。
- F使用不共享的模块，在相同循环预算上匹配主要前向运算结构，检验增益是否仅来自更深计算。
- A/E/F一起解释：单独A>E不能排除“只是算得更多”；单独A>F也不是参数量相同的比较。

优先保留重复seed，而不是20个各跑一次的超参想法。主条件A和辅助最充分的D各4seed，其余各3seed。

## 3. 数据边界和输入输出

### 3.1 来源题冻结

沿用`data/chain_loop`的语义记录和世界：

- E=500，R=20，world_seed=42；ER=10,000个随机置换原子事实。
- 40,000个不同w2来源行：两道独立一步题；全部事实各出现8次。
- 10,000个不同d2来源行：k=1图的20个有序关系对 × 全500个起点。
- 20个验证关系对，360个最终测试关系对；沿用已有train/val/test分割。
- 不改变训练关系列表、不新增d3来源行、不从测试集生成训练例子。

**重要：这份数据没有“d2已见关系对、未见起点”测试。** 每个训练关系对的500个起点已全覆盖，`all_seen|d2`是拟合检查；`one_new|d2`是未见关系对泛化。

k=1训练图构成关系环；all_seen深链可由首关系决定其余关系。因此主证据必须来自one_new和random，不能仅看all_seen。

50k=5ER个不同来源行，仍是按原子事实数计的线性规模；这不是不同E/R上的样本复杂度定理。格式增强后的不同输入数、重复呈现次数和辅助标签数分别统计。

### 3.2 保留完整w2，统一最终答案格式

概念输入输出：

```text
w2 输入：TASK e_x r_a EOP | TASK e_z r_b EOP
w2 输出：e_fa(x) e_fb(z) END_ANSWER

d2 输入：TASK e_x r_a r_b EOP
d2 输出：e_fb(fa(x)) END_ANSWER

测试输入：TASK e_x r_1 ... r_d EOP
测试输出：e_result END_ANSWER
```

w2两问保持在一次完整输入和一次latent求解中，不拆成外部原子调用。所有20个run使用同一新格式。模型不输出文字CoT、STEP、ADVANCE或读取位置。

decoder为普通自回归输出头，训练teacher forcing仅发生在最终答案串；答案token、正确中间实体均不回流到latent迭代。推理时答案串自由greedy生成。

### 3.3 固定地址范围，减少位置外推混淆

为了尽量把研究集中在组合，而不是新出现的绝对位置：每个输入使用两个固定TASK区。每区为131个位置：

```text
[TASK, 起点实体, 128个程序槽位, EOP]
```

- w2启用两个区，每区一个关系；d2及深测试仅启用第一区，第二区全空。
- 有效关系按程序原有顺序放入随机抽取后排序的槽位；空槽为EMPTY，静态attention mask屏蔽。
- EOP位置固定在本区最后，模型始终能看见它；不能把EOP是否可见作为外部“现在该停止”的信号。
- 输入逻辑地址域固定262位置。浅题通过随机布局覆盖1–128范围内的关系位置及间距；没有增加其语义深度。
- 不提供loop编号embedding、剩余步数标量或“当前槽位”标记。

训练布局由独立RNG产生，A–F同seed、同来源呈现使用相同布局；验证/测试布局提前冻结。每个程序仍保持左到右顺序，不能把打乱语义顺序当作无标签增强。

允许实现时压缩掉被mask的EMPTY以节省计算，但必须保持原始position IDs、TASK区坐标和所有有效token；dense与packed的输出/梯度/读取loss应在小测试上相符。EMPTY始终不参与key softmax分母，第二区未启用时整个区同样处理。逻辑窗口固定不等于有效指令数固定；深测试仍增加有效指令和候选关系数量，不能声称消除了全部分布变化。

随机稀疏槽位同时增加了“寻找下一个有效关系”的难度；d128又成为密集布局。因此负结果可能包含稀疏寻址和密度变化，不能直接否定连续紧凑程序上的所有latent组合方案。预定紧凑布局评估用来帮助解释，不能看到结果后替换主协议。

这是新输入协议，不与旧R/RC形成单因素架构对照。旧结果只作背景；本批因果对照是使用完全相同协议的A–F。

## 4. 模型：固定题目记忆＋自主latent更新

### 4.1 共同结构

```text
完整输入packet → Encoder → M（本次求解中固定）
4个learned latent slots → Z0

重复T次：Zt = Coreθ(Zt-1, M)

最终ZT → AnswerDecoder → 答案token串
```

固定M表示循环期间不覆写记忆，不表示冻结Encoder权重。Encoder在训练中正常接收梯度。

| 项目 | 本批固定设置 |
|---|---|
| hidden size / heads | 256 / 2 |
| 工作区 | 4个learned latent slots；初始化与程序深度无关 |
| 输入Encoder | 2层Transformer，输入内双向注意力；只读输入，不含任何目标token |
| Core | 2个相同结构的block；每block含latent self-attention、对完整M的cross-attention、4d GELU FFN |
| 共享 | A–D重复同一个2-block core；E只用一次；F有8份独立2-block core |
| 归一化 | pre-LayerNorm残差；不在本批同时扫归一化方案 |
| 位置 | RoPE base=100；M的逻辑位置固定0–261；latent槽位置固定262–265，不随t递增 |
| 初始化 | embedding/linear std=0.02；core各残差支路输出投影零初始化；其余按同一初始化规则 |
| dropout / precision | 0 / fp32 |
| AnswerDecoder | 1层因果self-attention＋cross-attention到最终Z；**不能直接读取M**；untied词表输出头 |
| 词表 | `chain_loop/vocab.json`的524项原样保留，再依次追加TASK/EOP/EMPTY/ANSWER/END_ANSWER，共529项；20run完全相同，导出映射/hash |

输入Encoder的双向注意力是本批统一结构选择。最终目标仍为条件next-token CE，但它不是与旧GPT2 decoder-only完全相同的架构。Encoder、core、decoder及辅助头参数量分项实测，不沿用旧模型1,852,416的数字。

每个core block的执行顺序为self-attention→memory cross-attention→FFN。所有有效M token在每一轮均可被访问；mask只表示静态输入有效性，不按进度变化。

**位置规则冻结：** Encoder self-attention对Q/K使用memory原始逻辑坐标0–261；core self-attention对Q/K使用latent坐标262–265；core cross-attention的Q用262–265，K用memory坐标。Decoder输入ANSWER从266开始，后续答案前缀位置逐token加1；其self-attention用这些位置，cross-attention的Q用答案位置、K用latent坐标。各模块均在自己的Q/K投影后应用RoPE，V不旋转；固定输入/latent的坐标不因packed长度、循环次数或已读取关系而改变。

一次答案生成只计算一次ZT，随后整个答案串复用它，不重新运行core。生成从ANSWER开始，遇END_ANSWER立即停止，统一最多生成4个token；w2正确串长3，d2及深题正确串长2。全词表greedy，不能依据期望答案个数强制实体token或强制END。

### 4.2 读取监督具体作用在哪里

C/D监督**第二个core block的memory cross-attention、latent slot0、head0**的实际soft attention概率。该头的weighted value正常进入残差路径，其余头和槽仍自由学习。

没有专门的oracle读取模块。不能把辅助标签作为attention mask，不能把soft attention替换为one-hot。命中被监督的头本身也不证明它是唯一执行通路，需要后续因果干预。

读取标签首先记录逻辑地址（第一区TASK=0、实体=1、关系槽=2–129、EOP=130），packed实现再通过每个样本的映射转换为key索引；不得用t或压缩序号代替逻辑地址。验证输出、梯度和读取loss的dense/packed一致性。

实体辅助头同样读取每轮结束后的slot0，经LayerNorm＋linear预测500类实体；所有A–F均实例化该头以保持参数和初始化RNG一致。无辅助条件中该头不产生训练梯度；诊断probe需另说明是否经过训练。

## 5. 损失与浅监督的精确定义

### 5.1 最终答案NTP：所有条件共同

每个来源packet有m个最终实体，w2时m=2，d2时m=1：

`L_ans = mean(各答案实体token的CE) + CE(END_ANSWER)`。

提示和输入token不计损失；w2两实体各权重1/2，d2答案权重1；END权重1。按来源行平均，再按256行batch平均。不能因为w2有两个答案就无意把来源行损失加倍。

decoder只看到最终Z和此前答案前缀；任何中间状态监督均不改变其输入。

### 5.2 辅助loss仅用于阶段二的d2来源行

为避免w2两问的内部槽分配额外引入监督，本批B/C/D的辅助loss**只作用于d2**。前50k w2阶段，A–D完全同训练目标；同seed应具有相同初始参数、数据、布局、T和损失轨迹（确定性配置下）。

阶段一必须完全跳过辅助loss计算图，不能先计算再乘0：后者可能产生零梯度张量，使AdamW对本应未使用的辅助头执行weight decay。用相同配置核对初始和前若干updates的参数hash；unused参数保持grad=None。

对d2题 `(x,r1,r2)`，标签 `x1=f_r1(x)`、`x2=f_r2(x1)` 只由这道浅题导出。

**实体辅助B/D：** 第t轮结束后，slot0实体预测目标为`t=1: x1; t>=2: x2`。不监督固定learned Z0为不同x，也不把probe输出重新嵌入Z。

**读取辅助C/D：** 第t轮上述指定头的目标为`t=1: r1所在槽; t=2: r2所在槽; t>=3: EOP槽`。对该实际注意力概率做负对数损失。标签只进入loss；t=2仍应读取r2，不能同时要求读EOP。

每种辅助loss先对该题实际T轮取平均；来源batch中w2的辅助loss为0，仍除以256来源行：

`L = L_ans + 0.5 * I_state * L_state + 0.5 * I_read * L_read`。

A/E/F：两个I均0；B：1/0；C：0/1；D：1/1。系数不按深测试调参。记录每类原始CE、梯度量级和标签曝光；相同来源题数不等于相同监督信息或训练FLOPs。

按T轮平均会偏重完成状态：T8时实体标签7/8为x2，读取标签6/8为EOP。本批保留此预定规则，另记录执行轮与完成后轮的loss/梯度。B/D同时包含状态学习和浅题终态稳定监督，C/D同时包含读取与浅题结束位置监督，不能把其效果全部归因于某一个细分机制。

B/C/D引入了浅题中“一轮对应一个语义步骤”的训练偏置。推理仍自主，但如果只有这些条件成功，应称为**浅执行监督诱导出的latent泛化**，不能称为最终答案监督下自行发现算法。

### 5.3 终态、END与预算

额外轮次的x2/EOP监督是在浅题上教稳定完成状态。没有显式HALT决策头，decoder的END只是答案格式结束。通过加T测试答案是否保持稳定，不能将其等同于学会自主选择计算时间。

## 6. 训练设置、匹配和20-run并行性

- 全部从零初始化，不加载L/O或其他预训练执行器。
- 250,000updates：前50,000每步256个w2；后200,000每步128w2＋128d2。
- AdamW，lr=3e-4，warmup=100，weight_decay=0.1，betas=(0.9,0.999)，eps=1e-8；梯度全局范数裁剪1.0，记录触发比例。
- 裁剪是针对前批loss尖峰的统一数值稳定措施，所有20run一致；不与旧无裁剪R声称单变量比较。
- A–D/F每update均匀抽T∈{2,4,8}，与题型和深度独立；E固定T=1。完整反向传播，不截断、不每轮detach，不分轮重置Z。
- 来源流、布局流、T流、初始化流、监测流分别使用独立RNG。评估频率改变不能改变训练流。
- A–E相同命名张量同seed初始化一致；F公共部分与A一致，core1对应A，其余core独立初始化，并保存初始化hash。
- 单次呈现的memory编码一次，core循环T次，答案decoder执行一次自回归输出过程。正式对照默认不缓存cross-attention K/V，避免A/F因缓存机会不同而声称严格同计算；所有配置一致并实测FLOPs。

**参数/计算声明：** E与A精确匹配参数，但少用计算。F与A在共同T上使用相同运算形状、近似匹配主要前向/反向FLOPs，F参数和优化器成本更多；实际FLOPs与壁钟均需记录。B/C/D有额外监督运算，不能称训练预算完全相同。

F只支持T≤8。其8份core按随机prefix训练，core1–2每步参与、3–4约2/3、5–8约1/3；记录真实参与/更新次数。不能把8个不共享core循环回头复用后仍称为非循环对照。

## 7. 评估、选点和成本

### 7.1 主结果和预算规则

深度：`2,3,4,8,16,32,64,128`；类别：`all_seen,one_new,random`。固定程序ID与已有120k语义测试题一致，另提前冻结布局；每格5000题。

两套预注册读数：

1. **共同计算范围：** A–D/F统一T=8，E保持其T=1结构；A–F全部跑完整120k。A与F可比较相同core调用数量；E作为少计算、同参数基线。
2. **共享循环扩展能力：** A–D统一T=256，在所有深度上跑完整120k；不是依深度指定关系或停止位置。允许出现overthinking退化，不能换成测试网格里最好的T作为主分数。

E没有T>1的主定义；F没有T>8的主定义，报N/A而非0。二者额外反复调用会成为另一架构，不能混入本批。

补充矩阵：A–D的T=`1,2,4,8,16,32,64,128,256`；F为`1,2,4,8`；E仅1。每个(类别,深度)固定500题，画准确率随T变化。该网格不用于选择最佳T或最佳检查点。

T=256不是“任意算法必然足够”的保证，只是预定有限预算；d128失败时结合整条预算曲线解释。

### 7.2 检查点与监测频率

- 主检查点固定250k，全部主评估和预算矩阵。
- 稳定性检查固定240k、245k：主T8/T256各用固定500题/格，减少三次全量深评估的成本。
- secondary best只在阶段二50k之后选：T8下`0.5×val_w2严格整行正确率 + 0.5×val_d2严格答案正确率`，平手用对应浅验证L_ans均值、再平手取更早update。E用T1；不把同一best当成公平主结果。
- best仅做500题/格的T8/T256诊断，不因看到深测试高分再扩充其全量评估。
- 训练日志每100步；浅验证与小监测在1k–5k每200步、50k–55k每200步，其余每5k。
- 密集监测深度2/3/4/8/32，one_new/random各64题，T8＋T64（E/F用可支持预算）；每25k另做全深度T网格，每格64题。
- 训练状态每5k保存完整resume checkpoint；密集监测保存指标和64题的原始答案，不要求保存每200步完整权重。

深监测只用于冻结方案后的曲线记录，不触发改超参、挑点、提前停止或追加训练。技术失败允许从最近完整状态续跑，但不能把不同优化器/裁剪配方的重启拼成同一个run。

### 7.3 确认集与位置控制

现有每格5000题中的前500固定为监测/诊断，后4500作为本批最终确认子集；同时报告全部5000以便历史对照。原有整个测试池已用于以往实验，因此这是新架构的预定确认子集，不是从未被研究者查看过的全新基准。

每25k的64题矩阵、密集监测、布局变化和后缀干预只能使用这前500或另行冻结的独立语义集合，禁止每次从全部5000重抽。启动前导出ID manifest并检查与后4500的交集；机制分析在最终行为评估之后开展，单独标记使用的数据。

固定主布局为有序随机槽位；额外500题/格使用紧凑布局（从第一个程序槽开始连续放关系），再对其中128题提供4种布局。报告同一语义程序跨布局的答案一致率，区分组合失败与格式敏感性。

### 7.4 必报指标

- 严格答案正确率：恰好输出应有数量的实体token，再输出END；错误格式单列，不允许“出现过正确实体就算对”。
- w2逐问准确率及两问同时正确率；全10k原子事实作诊断（单任务格式，只评估）。
- d2训练对拟合与未见对泛化；one_new按新邻接的归一化位置分桶。
- d3+的all_seen/one_new/random分开；repeated relation和entity revisit分层。
- 每一题在T8→16→…→256的错→对、对→错比例；额外计算后的答案稳定性。
- 来源行曝光、唯一语义来源数、唯一布局输入数、答案监督token、实体/读取辅助标签数、参数量、累计FLOPs、优化器步数、时间、峰值显存。

潜在模型没有显式执行轨迹，不能直接报告“完整轨迹100%”或“真实首错在第几步”。read-head命中率和probe实体正确率只作为标注清楚的诊断，不能冒充可观测内部执行真值。

## 8. 什么现象支持“组合泛化涌现”

### 8.1 预注册的行为判据

主要关注A；同时完整报告其他条件。

- **d2门槛：** final未见关系对严格答案≥95%，至少3个seed满足。
- **初步自主深组合：** 同一个预注册预算下，one_new与random的d3/d4/d8均≥95%，至少3个seed；240/245k的同预算监测也≥95%。
- **强深组合证据：** 同样标准扩展到d16/32/64/128；在报告中逐深度列出，不用单个平均分掩盖失败。
- 若未过95%，仍报告连续准确率与随机水平以上的部分能力；95%只是声明强成功的操作阈值，不把94%描述成毫无泛化。

在训练过程中定义`t_d(T)`：预定T下，one_new/random中较低的准确率首次≥95%且连续3个观测点维持的update。没有达到则记未达到；每个(d,T)按其实际采样间隔报告，密集窗口可到200updates、普通监测5k、仅全网格覆盖的深度/预算可能只能精确到25k。不同采样间隔的首次达标时间不能假装具有相同精度。

最有价值的图是“训练步数×组合深度”热图，以及同一个checkpoint上的“内部预算T×组合深度”热图。若更深组合随额外loop被逐步解锁、且超过所需预算后仍稳定，这是机制分析的切入点。曲线陡升本身不证明相变或算法发现。

### 8.2 因子效应与循环收益

在seed1/7/123上计算配对差，分别报告各深度：

- 实体监督主效应：`[(B-A)+(D-C)]/2`。
- 读取监督主效应：`[(C-A)+(D-B)]/2`。
- 交互：`D-B-C+A`。
- A/E：共享模型多轮计算相对同参数单轮的收益。
- A/F：在共同T2/4/8上的参数共享差异；不得用A/T256与F/T8声称同计算胜出。

报告每seed结果、均值与范围；样本级置信区间不能代替不同训练seed的不确定性。只有3个配对seed，不夸大统计显著性。

### 8.3 防止k1捷径和机械归因

预生成500对测试：保持相同起点与相同前缀，只改变后半段某个关系，选择两题gold答案不同的pair，固定depth3/8/32/128各125对。报告两题同时正确率和答案对后缀变化的响应，不用于训练或选点。

这检查模型是否使用完整程序，但不证明具体是串行读取。任何A–D出现深组合成功，都在与最终测试分开的机制样本上拟合轻量probe定位候选实体/进度，再做状态替换、同语义替换和无关子空间对照。C/D另检查屏蔽被监督读取头的影响及其他头对照，排除该头只是满足辅助loss的旁路。probe训练数据仅来自浅题；冻结后在深题测，不向主模型反传。

A不强制第t轮对应第t条关系，不能因其probe在该对齐上失败就否定算法；可能存在准备轮次、多轮一步或并行机制。只有在确认对齐之后，才检验“更换latent实体后，结果按剩余程序改变”。

## 9. 预期结果及如何解释

以下为可证伪预测，不是已有结果，也不承诺数值。

| 观察 | 更支持什么 | 仍不能声称什么 |
|---|---|---|
| A稳定通过深组合，并在共同预算优于E/F | 纯NTP与共享latent计算学出了可扩展规则 | 未经机制检查不能指定它一定逐关系串行调用 |
| A只在增大T后通过更深题 | 测试时内部计算对深组合有作用 | 与F/T8对比不是同预算；不等于自主停止 |
| B显著改善，C较弱 | 实体状态学习/保持的训练信号更有帮助 | 不足以证明所有失败都由状态表示引起 |
| C显著改善，B较弱 | 浅题读取监督有帮助 | attention监督同时改变表征，不能单凭准确率完成全部因果归因 |
| D成功，B/C都不成功 | 状态与寻址的联合训练可能必要 | 仍未实现A的纯答案自发发现目标 |
| A–D都仅d2成功 | 此配方仍无法从浅执行迁移到深执行 | 不证明所有latent/loop架构不可能 |
| A和F都成功，E失败 | 更深计算有益，共享不是已识别的必要条件 | 不能把所有增益归因于loop的权重共享 |
| E也成功且与A接近 | 新表示/输入结构可能已足够，loop独特收益弱 | 不能宣称发现loop特有“奇效” |
| 深题只在某个T高分，额外轮次破坏答案 | 部分预算对齐能力，终态稳定仍不足 | 不支持可靠任意步执行 |

我的方向性预期：D最可能先出现深组合信号，A风险最高但科学价值最大；E可能学会浅题，F可能拟合更好但未必更能外推。当前证据不足以可靠预测成功深度，因此不填写虚假的准确率预报。

浅数据对一般模型类仍存在欠约束：“执行两步后冻结”与“直到程序末尾持续执行”在w2/d2上都可能正确。参数共享本身不能排除内部计数捷径。本批测试的是结构和训练信号是否更偏好可复用规则，不是预先假定浅监督必然足够。

## 10. 实现前必须通过的检查

这里列的是未来实现验收项，本次文档交付没有执行训练。

1. 数据hash与来源计数验证，训练与选点模块不能加载深测试标签作为loss。
2. 前向接口只接受完整输入、有效mask和预算T；gold实体/读取位置仅由loss模块使用。固定输入/权重时修改gold标签，前向输出必须不变。
3. 记录每轮memory checksum不变；Z持续更新，无每轮detach或reset；全循环梯度能回到早期core。
4. 更改后缀关系能改变M与候选模型输出；无仅取头两个关系的截断bug；d128无输入截断。
5. dense/packed地址布局一致；PAD不影响有效位置；训练布局与测试position范围审计。
6. A–D同seed第一批参数和50k前损失一致（允许声明并测量数值容差）；辅助头初始化不能扰动主网络RNG。
7. E与A参数数量完全相等；F8份core不是同一对象或共享storage，prefix和梯度参与次数正确。
8. decoder没有直接读取M的旁路；答案teacher forcing不进入latent loop；评估全词表greedy且严格解析格式。
9. 保存完整resume状态：模型、优化器、RNG、来源流、布局流、T流、曝光计数；续跑与不中断小样本轨迹一致。
10. 固定小batch测A/E/F实际参数、前向/反向FLOPs、T8/T256耗时和显存。技术smoke只查实现和吞吐，不据深泛化表现修改20run方案。

若技术检查需要改动语义协议或损失，应更新方案版本并在正式训练之前重新冻结。不是要求再向用户提出例行实现确认，而是要求运行记录准确反映最终设计。

## 12. 本批暂缓的方向

新世界43/44、E/R scaling、held-out关系仅w2出现、w2-only、k1→k4、多种位置编码、RL、大规模超参搜索均留待后续。当前优先回答“自主latent执行是否出现、需要哪种浅信号”。本批结论因此限于当前世界、关系角色覆盖与k1来源分布。

## 13. 理论与文献定位

固定输入可反复访问、共享core更新latent状态的设计与[Geiping等的recurrent-depth架构，§3](https://arxiv.org/html/2502.05171v2#S3)相关；本文的小型工作区、浅数据边界和辅助因子实验是本项目的具体假设，不是该论文已经证明w2/d2可泛化到任意深度。

[Coconut](https://arxiv.org/abs/2412.06769)把连续隐藏状态作为后续输入，提供了研究latent推理的另一种实现参照。本批没有复现其完整训练课程，也不能借其结果替代本项目严格浅监督的验证。

如果未来要提出任意深度理论，需要证明或充分验证：初始化落在可解释的状态域；共享更新将可达状态映射到下一步仍可用的状态域；完成状态在额外循环下可正确读出或保持稳定。浅题probe和d128有限高分都不足以自动建立这些全域条件。
