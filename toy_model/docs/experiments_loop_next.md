# 下一步实验：从 w2/d2 学习可重复执行的组合规则

日期：2026-09-17。

状态：实验计划与事前预测，尚未实现或运行。依据第三批 chain 实验的独立核查。第一轮包含 4 个新训练臂 × 3 seeds；先实现与核验接口，再提交正式训练。

## 0. 摘要：做什么，为什么做，预计看到什么

目标是只用 w2/d2 来源数据，通过 next-token prediction，学习能在未见组合及更深链上复用的操作。分开检验两个命题：

1. **能力命题：** 有固定局部执行接口时，浅层数据是否足以学出支持任意有限深度的更新与停止规则？
2. **机制命题：** 只有共享计算、没有外部局部接口时，模型是否会自行学出可迭代的状态与控制？

| 臂 | 数据：唯一来源题数 | 模型获得的执行接口 | 核心问题 | 事前预测，不是实验结果 |
|---|---|---|---|---|
| F：已有 C_k1 | 40k w2 + 10k d2 | 全任务输入，完整历史 CoT | 原始参照 | 已知 d2 新对成功，best/final 的 d3+ 完整轨迹失败 |
| O：外部控制循环 | 复用 C_k1，不新增训练 | 程序供给正确关系顺序、规范短提示和停止 | 已有更新能力能否重复调用 | 单步全表正确时，应成功；属于外部控制正对照 |
| **L：局部学习执行器** | **40k w2 + 10k d2 = 50k** | 当前实体、当前关系/EOS；每次重置；模型预测 STEP/ADVANCE/HALT | 规范局部规则能否支持深组合 | 最有希望稳定成功；收敛时间与是否全表正确仍需测量 |
| **L-w2：同一执行器，只用 w2** | **40k w2** | 与 L 完全相同 | d2 在接口局部化后是否还有独立作用 | 匹配曝光后应接近 L；局部输入支持与期望监督分布相同 |
| **L-history：允许读取此前调用** | 40k w2 + 10k d2 | 与 L 相同的当前观察、动作与位置编号；另保留同一任务的历史 | 历史访问是否破坏操作复用 | 深链可能更不稳定；也可能学会忽略历史而与 L 一样成功 |
| **R：内部 latent loop** | 40k w2 + 10k d2 | 完整任务输入；共享 Transformer 模块反复计算 | 权重共享能否自行产生可迭代计算 | 最不确定；预计不如 L 稳定，可能只有局部改善或过度循环退化 |

**最重要的预期：L ≈ L-w2 是合理的正结果。** 在局部模型只能看到 `(实体, 当前关系/EOS)` 的条件下，d2 的关系配对身份已经从输入中消失。成功可说明浅层事实学习与规范接口足以支持组合复用，不能据此声称 d2 触发了自主递归算法。

## 1. 现有证据怎样决定本轮问题

第三批已确认：

- C_k1 用 50k 题、20/400 个训练关系对，三个模型 seed 的 best/final 在 d2 未见关系对上均为 100%，完整轨迹也正确。
- 已完成评估的严格 w2/d2 CoT 臂，best/final 在 d3–d32 的完整轨迹均为 0。少量偶然正确的尾实体不构成可靠执行。
- C 的规范单步接口可在全部 10,000 个实体–关系输入上正确；部分检查点的外部逐步调用也已成功。普通 C 的已核查外部补评覆盖 seed 1、每格 300 题，不能扩大为所有模型的全量结论。
- C 的 d3 错误包含选错关系与执行两步后停止；更长历史中更新本身也会退化。
- NoPE s7/220k 在探索性 500 题单元上曾达到 d3 完整轨迹 21.2%（全部邻接已见）、1.8%（一个新邻接）。这是中途信号，不是主选点的稳定成绩。

因此，本轮重点是 **接口是否在重复调用时保持不变，以及共享计算是否能学到同样的复用**。不再把增加关系伙伴数作为首要变量。

## 2. 严格边界与预算口径

### 2.1 允许什么

- 所有新模型从头训练；任务来源只包含 w2 和 d2。
- w2 是一行中两个独立的一步任务；d2 是一个两步组合任务。
- 允许把已有浅任务的答案与中间实体编译成局部执行轨迹，使用 NTP 监督动作。
- 原来的一个来源题仍是一个采样与损失归一化单位，记录 `source_id`、子任务与调用编号。

### 2.2 不使用什么

- 不用 d3+ prompt、答案、过程轨迹、奖励、伪标签或课程训练。
- 不用长链表现选择模型检查点、训练时长、超参数或推理循环次数。
- 本轮不加 RL；RL 之后只能在同一浅层任务池中作为独立优化对照。

### 2.3 必须披露的接口变化

L 系列只用 **w2/d2 来源任务**，但每次网络调用接收的是局部一步观察。这是任务展开与执行接口的改变，不能称为保持原始完整序列格式不变。

若使用更强限制“每次 forward 都必须看到完整 w2/d2 序列”，L 不属于该限制下的方法；R 属于完整任务输入路线。两类结果分别报告。

分别统计：唯一来源题数、唯一原子事实数、来源题重复次数、实际/带损失调用数、可见与监督 token 数、优化步数、GPU 时间和推理调用数。50k 唯一题不等于 50k 总训练曝光。

## 4. L：最小局部执行接口

### 4.1 观察与预测

每个观察只包含当前实体和指令流的头部，不包含步号、原始深度、剩余长度或此前隐藏状态。

```text
OBS STATE e377 HEAD r19 ANS
→ STEP e63 ADVANCE END_CALL

OBS STATE e63 HEAD r14 ANS
→ STEP e92 ADVANCE END_CALL

OBS STATE e92 HEAD r13 ANS
→ STEP e478 ADVANCE END_CALL

OBS STATE e478 HEAD EOS ANS
→ HALT e478 END_CALL
```

其中三步示例仅解释测试时行为，不能进入训练。实际训练每个独立子任务只有一或两步。

### 4.2 程序与模型分别负责什么

**程序提供：** 保存输入关系序列、读取当前 HEAD、执行 ADVANCE、保存模型返回的实体、重置调用上下文。它不实现关系置换、不计算正确实体、不替模型修复动作。

**模型学习：** 当前实体如何更新、什么时候输出 STEP/ADVANCE、什么时候输出 HALT、HALT 时返回哪个实体及合法格式。

关系序列本身已经给出执行计划；本轮不要求模型重新生成整份计划，也不要求复制剩余列表。

### 4.3 推理规则

1. 每次调用清空上下文、KV cache、隐藏状态；位置编号从同一位置开始。
2. 只使用模型预测的下一实体，后续调用绝不替换成正确中间实体。
3. 非终点 HALT 记录为提前停止；EOS 后输出 STEP/ADVANCE 记录为越界动作；非法格式直接失败。
4. 不依据 HEAD 使用强制解码来禁止错误 STEP/HALT。两种选择都应由模型自己做出。
5. 每次输出上限固定为 6 token；合法 STEP 为 4 token、HALT 为 3 token，END_CALL 前额外内容判错。END_CALL 之后不属于本次记录。
6. 每个任务的调用上限为 d+2，仅作资源上限。达到上限不算正确停止；该数字不输入模型。
7. 输出原始 token、模型动作、预测实体、输入 HEAD、当前指针与停止原因，便于完整重评分。

该接口把关系选取局部化，并提供了外部指令流。结果应称为“学习局部执行规则”，不能称为完整任务中的自主 planning。

## 5. 为什么要有 L-w2 与 L-history

### 5.1 L-w2：检验 d2 是否提供额外局部信息

一个 w2 来源题包含两次 STEP；一个 d2 来源题也包含两次 STEP。全覆盖数据使两者都覆盖所有 `(x,r)`。由于关系是置换，终点也覆盖所有实体，从而覆盖所有 `(x,EOS)`。

在 L 的输入限制下，平衡曝光之后，两种数据的局部输入支持与期望监督分布相同。随机选择 w2 终点并不保证有限训练中 EOS 频次完全一致，因此实际累计曝光仍需审计。L-w2 与 L 也可能因小批量相关性、重复顺序与优化噪声而收敛速度不同，但没有新增的局部关系配对信息。

**解释规则：** 若 L-w2 同样成功，是对数据效率的加强；若 L 长期显著优于 L-w2，先核对输入、覆盖、曝光与目标权重，不直接解释成组合机制涌现。

### 5.2 L-history：只改变历史可访问性

使用与 L 相同的观察/动作帧、来源题、目标与损失权重。训练使用浅任务的正确状态；测试反馈模型自身预测。

- L：每个调用只能注意到当前帧。
- L-history：当前调用可以因果地注意到同一独立任务中的此前观察和动作。
- w2 的两个独立子任务之间重置；d2 内两步与终止调用之间保留历史。
- 两臂都采用每个调用重新从零开始的 RoPE position IDs；因果 mask 仍按真实 token 先后顺序构造。

这样主要变化是跨调用历史访问。若实现改用 L-history 的全局递增位置，必须改名为“历史＋位置联合消融”，不得单独归因于历史。首轮不加入该额外变体。

L-history 仍由程序提供当前 HEAD。因此它若成功，不能据此说模型已经解决了原始 C 中的关系选择；它说明在这个接口下历史重置并非必要。

## 6. R：共享 Transformer 的内部循环

R 保持完整任务输入，采用答案级 NTP，不新增中间状态或动作监督：

`h^(0) = Embed(prompt)`

`h^(t+1) = B_theta(h^(t))`

同一个 2 层模块 B_theta 反复应用；最终状态预测答案与 END。各 token 的自回归预测使用同一预先指定的循环预算。

首轮固定设置：

- 2 层共享模块、d_model=256、2 heads、RoPE base=100、untied embeddings、dropout=0、max_len=512。
- 保留普通 causal attention；循环内位置编号保持输入位置不变，不新增循环编号 embedding。
- 训练每个 batch 独立抽取 T∈{2,4,8}，等概率且不依赖题目深度。
- 为减少重复残差的不稳定，模块 attention/MLP 的输出投影采用零初始化；其余初始化、优化器规则记录到 manifest。
- 首轮不叠加输入注入、学习停止或多种位置编码扫描。
- 测试 T∈{1,2,4,8,16,32,64,128}，呈现完整“任务深度 × 循环次数”矩阵。不得为每个深度取测试集最优 T 作为主成绩。

**主读数：** 固定 final checkpoint，采用预先规定的 `T(d) = 最小不小于 max(8,d) 的二次幂`，在本轮最大为 128。它按输入深度分配计算，不使用答案或测试成绩；属于外部提供的计算预算，不代表模型学会停止。另报告固定 T=8 的对照，区分计算量不足与规则不能复用。不能只给 d128 同样的 8 次计算，再把失败全部归为组合能力不足。

完整 5,000 题/格用于主预算 T(d) 的 final 评估。全 T 矩阵只在预先固定的 50k、150k、250k 检查点上，用每格固定 500 题计算；常规训练曲线使用 T(d) 的固定监测集。先控制评估成本，不能事后从矩阵选一个最优预算替换主成绩。

R 是探索性架构组合：共享计算、随机循环预算与稳定初始化一起改变。已有 A/B/C 并不是相同数据、初始化与算力下的完整因果对照。若 R 成功，再补同数据的 T=1 答案模型、相同有效深度的非共享模型，并分别匹配参数和计算预算。

R 的内部轨迹没有被监督或直接输出，不能将内部探针的读数称为完整执行轨迹准确率。

## 7. 训练、曝光与模型选择

### 7.1 训练日程

沿用 250k updates：前 50k 只用 w2；后 200k 每批 128 w2 + 128 d2。batch 按来源题计，为 256。L-w2 在后阶段用额外 128 个 w2 替换 d2。

L 系列参数规模与 R 相同，采用默认初始化；所有新臂共用冻结的扩展词表，以免动作词表大小成为额外参数量差异。AdamW：lr=3e-4、weight decay=0.1、warmup=100，dropout=0，完整保留 optimizer、RNG、数据流状态。L-history 配置 max_len=4096，以覆盖 d128 的调用记录；实际序列长度、mask 和 position IDs 必须先核验。局部 L 的一次调用很短。

本轮各臂均跑固定 250k，不因深链曲线好坏延长或早停。若数值崩溃或任务拟合失败，保留失败结果；修正配方另立实验，不能悄悄替换。

### 7.2 L 系列的精确曝光匹配

每次来源题呈现包含两次带损失 STEP。d2 有一个终止调用；w2 有两个，使用冻结 RNG 均匀选一个施加 HALT 损失，另一个不计损失。完整浅任务轨迹仍可被序列化；无损失的可见 token 也要计数。

因此每个来源题呈现固定提供 **2 个 STEP + 1 个 HALT 监督调用**。调用内部 CE 先对输出 token 取均值，再定义：

`L_row = 0.5 × mean(L_STEP1, L_STEP2) + 0.5 × L_HALT_selected`

最后对 256 个来源题平均。观察、HEAD 与运行程序提供的字段不计预测损失。此权重是首轮固定选择，各局部臂相同。

L 与 L-history 使用相同来源题顺序、HALT 选择、参数初始化与损失。L-w2 匹配来源题呈现次数、STEP/HALT 监督次数和学习率日程。审计每个 `(x,r)` 与 `(x,EOS)` 的实际累计曝光。

F/R 使用各自的输出协议损失，所以它们与 L 的比较是方案比较；不能把差异全部归因于某一种监督 token。

### 7.3 主检查点与稳定性

- **主检查点统一为 250k final。**
- 每 5k 保存检查点与优化器状态。
- 若提供次要 best 结果，所有新臂使用相同的 w2-only 验证任务，按自由执行完整正确率选点，平手用 w2 loss。每臂使用自己的固定执行协议。
- L-w2 不得使用 d2 标签选点，否则只能称“无 d2 梯度训练”，不能称严格 w2-only。
- 固定报告 240k、245k、250k 三个末期检查点；稳定性不能用任意挑选的最佳窗口代替。
- d2 与深链监测可按固定流程计算，但不反馈训练/选点/延长规则。世界 42 上的机制分析属于开发；独立确认另用新世界。

## 8. 测试矩阵与成功标准

### 8.1 任务

d∈{2,3,4,8,16,32,64,128}，每个深度包含：

1. 所有相邻关系对来自训练图。
2. 恰一个邻接位置来自最终新对测试池，位置均衡。
3. 随机链，排除模型选择用的验证边。

每格冻结 5,000 题；固定监测集每格 500 题。记录题目是否重复，保留重复关系、实体回访和回环，单独分层。新关系对的出现位置不能与停止/输出协议存在额外提示。

### 8.2 指标

- 格式合法、正确停止条件下的最终答案准确率。
- 可观察轨迹模型的全部状态与动作正确率。
- 原始末实体命中率，仅作诊断，不能替代合法完成。
- 第一次错误的位置、更新错误、动作/停止错误、格式错误。
- 每步生成覆盖率与 own-update 的实际分母；漏掉的步骤不能被高条件准确率掩盖。
- R 报告最终答案与计算次数；前缀重测或内部 probe 均单列，不能冒充它的实际完整轨迹。

主经验目标：L 系列在三个 seed 的 final 检查点上，每个 d3–d128 主单元的完整轨迹准确率均达到 **99%**。同时报告分子/分母、区间和三个末期点；99% 是操作目标，不是理论阈值。R 用合法最终答案作对应行为目标。

强验证目标：局部执行器在 **10,500 种规范输入上全部正确**，见 §9。达不到全表正确时，不做任意有限深度保证。

## 9. 精确局部表、错误分解与有限验证

### 9.1 每个检查点导出局部预测表

对 L/L-w2 枚举：

- 10,000 个 `(实体, 关系)`。
- 500 个 `(实体, EOS)`。

保存原始 greedy token、实体输出、动作、格式有效性和 logit margin。这里是训练覆盖域的穷举核验，不能叫 held-out validation。

用这份模型预测表重放相同测试链，每一步反馈表自身预测的状态。它保留关系/实体相关错误、重复访问、循环、提前停止与错误抵消，比假设独立错误的 `p^d` 更准确。

局部确定性模型的表重放应与实际调用一致。在固定的 50k 与 250k 检查点，对每个测试单元抽取 100 题执行真正的网络调用，与表重放逐步核对。若不一致，检查 batch 数值差异、隐藏状态、cache、解析器与上下文泄漏，不宣布验证成功。这些抽查验证实现一致性，不证明跨 batch、精度或硬件的数值不变性；证书仍以固定的确定性执行行为为前提。

### 9.2 四种重放诊断

| 更新 | 动作/停止 | 用途 |
|---|---|---|
| 模型预测 | 模型预测 | 原始局部执行表现 |
| 模型预测 | 正确控制 | 隔离状态更新误差 |
| 正确更新 | 模型预测 | 隔离控制误差 |
| 正确更新 | 正确控制 | 检查运行程序与计分 |

后三项是干预诊断，不是自主成绩。缺少实体输出、非法格式等问题单列，不能以“修控制”的名义默默填入正确实体。完全正确的基准臂显式使用规范记录。

### 9.3 任意有限深度的条件命题

若固定模型在每个 `(x,r)` 上输出正确 `STEP f_r(x) ADVANCE END_CALL`，在每个 `(x,EOS)` 上输出 `HALT x END_CALL`，且运行程序正确读 HEAD、执行 ADVANCE、反馈模型状态，则对任意有限链正确。

证明：每一步保持“当前实体等于已消费关系前缀的真实执行结果”；每次 STEP 消耗一个关系，剩余关系数严格减少；耗尽时 HALT 返回该实体。

前提包括：同一确定性推理配置、每次完整重置、无步数/历史等隐藏输入、解析与运行程序正确。该结论只覆盖固定世界与指定接口；R 和 L-history 不满足有限局部输入假设，不能套用此证书。

“d∞”在此指给足运行时间与外部指令存储后的任意有限深度，不指有限资源内执行无限步。L 的每步网络计算规模固定，总执行成本随 d 增长。

## 10. 怎样分析 emergence，而不把评分效应误作机制

生成两类图：

1. 所有臂的“训练步数 × 测试深度”准确率热图；L 系列同时画局部更新/控制错误数。
2. R 在固定检查点的“测试深度 × 推理循环次数”热图。

描述性起点读数：`t_d` 为首次连续三个监测点达到 95% 的第一个点。L 系列用各类别完整轨迹准确率的最小值；R 用主预算 T(d) 下各类别合法最终答案准确率的最小值，其训练步数热图也固定使用这一预算规则。固定 T=8 和全 T 矩阵单列，不能混成同一条曲线。报告所有 t_d 与其间距，不以该读数选择主检查点。

如果多个未训练深度在相近时刻一起成功，这是值得研究的现象，但不能单独证明发现了算法：平滑下降的单步错误也会造成长链 exact-match 的陡升。

**L 的主要机制检验：** 精确局部表是否完整解释深链曲线？若完全解释，则应表述为“局部规则学准后，在给定循环接口中产生深组合能力”。

**R 的更强机制检验：** 除跨深度行为外，需要发现可复用状态，并做因果干预，例如替换某个被识别出的中间状态后，后续输出是否随正确剩余操作改变。线性 probe 或 logit lens 只提供候选状态，不能独立证明算法。干预位置的开发与确认分开。

不存在必须观察到突变的要求。平滑改善、失败和暂时成功后退化都应完整报告。

## 11. 事前预测与结果分支

以下是根据已有结果和接口结构作出的预测，不是承诺，也不是统计置信区间；不预测具体涌现步数。

| 预测 | 依据 | 若出现相反结果，意味着什么 |
|---|---|---|
| **L 最有希望获得稳定深链成功** | 原有模型已能学准全部单步映射；新接口消除了未见长度的关系读取与历史状态差异 | 若局部表不全对，先处理学习/优化；若局部表全对而深链失败，检查执行与推理一致性 |
| **L-w2 与 L 最终接近** | 两者覆盖相同局部输入，匹配后目标分布相同 | 持续差距提示曝光、优化相关性或接口隐藏差异，需要先审计 |
| **L-history 可能弱于 L，但也可能成功** | 历史扩大了实际输入域；明确 HEAD 又让忽略历史成为可行策略 | 若一样好，不能再说上下文重置是必要条件，应聚焦显式 HEAD/接口设计 |
| **R 比 L 更不确定，单靠 loop 可能不足** | 已有浅监督允许多种短任务解法；相近论文的 2-hop 阶段亦未外推 | 若跨 seed/世界稳定成功，优先补公平架构对照和内部状态因果分析 |
| **增加推理循环可能先改善再退化** | 循环未必是单调推进；隐藏状态可能漂移或答案被覆盖 | 若始终稳定，要检查是否形成停止后不再改变答案的状态，以及是否只是浅任务固定点 |

决策规则：

- **L/L-w2 成功、R 失败：** 主要结论是规范局部接口使浅数据支持可重复组合；自主内部算法仍未解决。
- **L 成功、L-history 失败：** 支持在当前协议中限制历史访问有帮助；不能自动推广到所有历史模型。
- **L 与 L-history 都成功：** 本轮不能区分显式 HEAD、状态输入格式和动作监督各自贡献；下一步做逐项消融。
- **只有外部控制 O 成功：** 原子更新可用，但新动作/终止接口尚未学好；先定位错误，暂不增加 planning 模块。
- **R 也成功：** 冻结配方，补相同数据/初始化及等算力或等参数对照；再做新世界和状态干预。
- **只有测试峰值成功：** 记录为探索性暂时能力；不替换 final，不把其称为稳定 emergence。

4. 完成 O 的规范单步与外部循环检查。复评 NoPE s7/220k 与 s123/90k 的新题属于独立探索，不参与新臂选择。

### 阶段 P1：12 条新训练轨迹

L / L-w2 / L-history / R × seeds 1/7/123，各 250k updates。实现 smoke 不计正式结果；若 smoke 导致设计改变，先修订并冻结文档，再开始正式运行。

资源记录应包括各臂的实际耗时和调用/token 数。相同 updates 不等于相同 FLOPs；本轮没有依据给出可靠小时预算。

### 阶段 P2：冻结后的确认

- 对成功配方，在 world seeds 43/44 上各跑相同的三个模型 seeds，重新冻结世界、关系图和测试题。
- 再检验 E/R scaling：先固定 E=500，R=10/20/40，沿用 k=1；L 的来源题预算分别为 25k/50k/100k，再独立改变 E。
- 保留 H 仅在 w2 出现的版本，测 TT 新对、HT、TH、HH 与混合长链。L 中若所有关系共享同一规范原子接口，预计 H 能迁移；这同样属于接口带来的可复用性。
- 若要研究真正 planning，需要另定义“关系序列未知、模型必须选择路径”的任务；不能把当前给定关系序列任务的成功称为搜索规划。
- RL 与更复杂 CALL/RETURN 放在定位瓶颈后进行。所有训练历史仍不得引入 d3+ 问题，否则单列为放宽约束的对照。

## 14. 文献依据与适用边界

1. [Loop, Think, & Generalize: Implicit Reasoning in Recurrent-Depth Transformers](https://arxiv.org/html/2604.07822v1)，2026。共享层模型出现系统组合泛化的三阶段 grokking；其深度实验采用逐步加入更深任务的课程。Appendix F 说明只学到 2-hop 时尚未外推。它支持测试共享计算，也说明不能把 loop 当成满足本项目浅数据约束的现成解法。
2. [Making Neural Programming Architectures Generalize via Recursion](https://people.eecs.berkeley.edu/~dawnsong/papers/iclr_2017_recursion.pdf)，ICLR 2017。通过递归调用、调用状态重置和有限基础/递归规则覆盖，研究强泛化与可验证性。执行栈和递归结构由架构支持、训练包含执行轨迹，与本轮局部接口路线相关；其任务规模不能直接换算成我们的 d2。
3. [Re-Tuning: Overcoming the Compositionality Limits of Large Language Models with Recursive Tuning](https://aclanthology.org/2024.acl-long.561/)，ACL 2024。模型学习递归调用，由外部运行程序开启新上下文并返回结果。可借鉴 CALL/RETURN 的接口分工，不能把其预训练与训练数据条件当作本项目严格 w2/d2 的证据。

项目证据：服务器仓库 `toy_model/docs/experiments_chain_batch1.md`、`WALKTHROUGH.md`、对应 `runs/chain_*/metrics.jsonl` 与 `final_eval_*.json`；本地独立核查为 `results_review_chain_batch3_2026-09-17.md`、`chain_metrics_audit_2026-09-17.md`、`chain_eval_audit_2026-09-17.md`。

## 最终预期

本轮最有把握争取的结果是：**用 O(ER) 的浅层来源数据学准局部规则，借助明确的执行接口，获得可检验乃至条件性可证明的任意有限深度组合。**

更强、也更不确定的结果是：**共享内部计算在没有这种局部接口的条件下，自行形成可重复使用的状态与控制，并出现稳定的新深度泛化。**

两者都值得研究，但必须分别命名、分别取证。
