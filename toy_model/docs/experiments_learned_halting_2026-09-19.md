# 下一步主对照：人工按hop循环 vs 模型学习停止

日期：2026-09-19。用户最终指定的主对照为两组：**D：人工按hop设R=d；H：模型自行学习循环多少次。** 两组使用同一个全序列共享loop Transformer骨干、相同的浅层来源数据与最终答案标签。本文更新实验设计，未实现、未冻结运行manifest、未提交训练。

骨干及原子数据沿用[论文方法对齐规范](experiments_paper_aligned_loop_2026-09-19.md)。学习停止是用户新增扩展，不能称为《Loop, Think, & Generalize》的原样复制。此前的随机循环、固定阈值停止和额外停止标签方案保留为后续候选，不加入本次两组主对照。

## 1. 模型输入与计算

一次输入完整查询Q=[x,r1,...,rd]，不逐轮由程序送入r_t，也不提供中间实体。初始嵌入后：

```text
H_t = F_theta(H_(t-1))                  # 同一个共享causal stack
z_t = LN(H_t[最后有效输入位置])
p_t = sigmoid(w_stop^T z_t + b_stop)    # 同一个stop head
a_t = softmax(W_tied z_t)              # 同一个最终实体预测头

若模型选择CONTINUE：继续更新H_t
若模型选择STOP：输出a_t的实体预测
```

这是每个样本的停止决策，不是整个batch共同的R。已停止样本需从active batch移出或冻结，不能继续更新后替换其答案。

不新增hop数标量、每轮索引embedding、gold指针或外部关系选择器。模型能从完整输入感知长度和关系顺序；禁止这些额外输入不意味着模型看不到长度，也不保证其不会学习长度捷径。

逐轮判断优先于先把输入映射成一个固定类别的R：前者的CONTINUE/STOP动作集合在深题中不变。仍需通过实验检验它能否超出只见过1/2跳的训练范围。

推理设全体深度共用的最大循环上限B_eval，具体值待manifest冻结；它只用于限制资源。到上限仍选择CONTINUE记为timeout，不能记作自主停止成功。不得根据真实d强制STOP或选取轮数。

## 2. 主候选：只有最终答案标签的学习停止

优先研究可微的概率停止策略，参考ACT/PonderNet思想，具体实现属于本实验变体。

令p_t为在此前未停止条件下本轮停止的概率，则终止时间概率为：

`q_t = p_t * product_(j<t)(1-p_j)`。

候选目标是期望终止答案损失加计算成本：

`L = E_(T~q)[CE(a_T,y_final)] + lambda * E_(T~q)[T]`。

所有可能停止轮共享同一个最终实体标签；没有第t跳的gold实体或目标循环次数。这是在可能终止时刻上优化最终答案，不是中间步骤监督。为保持首批只有D/H两组，H建议先用lambda=0，先检验能否正确停止；弱正lambda作为后续计算效率消融，避免本轮同时引入提前停止压力。它是对普通固定轮数NTP训练目标的扩展，不能描述成未改动的固定轮数CE。

有限训练展开B_train需明确尾部概率如何处理。可选实现是在最后展开轮收集剩余概率用于截断期望损失；这部分必须记为截断质量，不能算模型主动选择STOP。B_train不得直接绑定每题d；只使用原子/d2语义数据，但允许在这些浅题上多轮展开。训练展开次数大于2不等于新增d3+数据。

推理可按p_t逐轮采样；若改为固定概率阈值的确定性决策，需预注册阈值并单列其与训练分布的差异。所有阈值及成本超参数只按浅验证选择，不能用深题答案调节。最终训练manifest必须冻结展开、尾部质量处理、推理决策方式和所有预算。

另一候选是RL：动作CONTINUE/STOP，STOP时以最终答案正确性提供奖励，另加弱每轮成本，timeout不给正确停止奖励。RL仍不能自动排除最多两轮的捷径；先做可微方案以减少同时引入的优化变量。

## 3. 用户确定的两组主对照（非已冻结run清单）

| 项目 | D：人工按hop给循环次数 | H：模型学习循环次数 |
|---|---|---|
| 原子训练 | 运行1轮后输出 | 模型逐轮选择CONTINUE/STOP |
| d2训练 | 运行2轮后输出 | 模型逐轮选择CONTINUE/STOP |
| d3/d4/d8等测试 | 分别运行3/4/8轮后输出 | 不提供目标轮数，模型自行停止 |
| 最终答案标签 | 同一最终实体y | 同一最终实体y |
| 训练目标 | 第d轮答案CE | 终止分布加权的最终答案CE；首批建议lambda=0 |
| 额外过程标签 | 无 | 无STOP=[t=d]、中间实体或读取位置标签 |
| 外部程序职责 | 根据输入关系数量设预算 | 执行模型动作，达到统一上限仍未STOP则记timeout |

D中的d由完整输入的关系数量得到，不需读取答案或gold轨迹；这属于外部计算预算先验，不是向模型传入每轮应执行的关系。两组都一次性输入完整程序，内部关系选择与状态更新都由模型学习。D成功不算学会停止，H必须主动停止且答对。

### 3.1 匹配项与不可混淆的差异

- 共用world42、10k独立atomic来源、40k w2来源、10k d2来源、相同训练/验证/未见关系对测试划分；d3+仅测试。
- 共用4-layer、width768、12-head、NoPE共享stack、tied答案头、初始化、optimizer、学习率日程、输入渲染、loss按查询计数规则。
- 配对seed使用相同来源抽样顺序及共享骨干初始参数。训练数据抽样、模型初始化、停止策略RNG相互独立，增加stop head不能改变其余参数的初始值。
- H额外需要stop head（若用上述线性头则为769个参数），如需相同模型容器，D可实例化但不使用该头；不能将D未训练的停止头用于公平的自主停止评价。
- 主比较优先匹配数据曝光和optimizer updates；同时报告实际训练展开/反传次数、总block计算量及推理循环分布。H的训练上限展开与D的1/2轮计算不同，不能宣称同更新数就是同算力。
- 这比较的是两个完整的训练及停止协议，不是严格只有推理开关不同的因果消融。用§4的同一H checkpoint停止方式切换进一步定位原因。

建议配对seed为1/7/123，即2条件×3seed共6个run；这是建议规模，不是已提交任务。updates、H的训练展开上限、停止决策规则、统一评估上限、w2渲染及选择checkpoint的浅验证规则需在运行manifest中冻结。不能用深测试选checkpoint或停止超参数。

### 3.2 w2计数

w2仍有未决的联合/独立渲染选择；两组必须采用同一选择。若拆成两个原子查询，D每题1轮，H每题独立停止。若保留联合w2，两项独立任务的语义深度仍为1；D预算1轮，H在联合答案完成时停止，但必须先明确两个答案的共同读出接口。不能把两个并行一步任务误作两跳，也不能一组拆开、一组联合。

### 3.3 本轮不扩展的备选

随机R、固定分布阈值停止、正计算成本和显式浅层停止标签均保留为后续候选。尤其STOP=[t=d]会提供额外过程监督，不能混入H后仍称只从最终答案学习停止。

## 4. 必须区分停止、执行和一步一跳

按原子、未见关系对d2以及d3/4/8/16/32/64/128分别报告D/H。D主指标是第d轮最终实体准确率；H主指标是**模型主动停止且答案正确**的比例。另报H的timeout、错误停止、平均/分位循环数及T随d变化；D的T固定等于d，不将其记作学会停止。

H在每个选定checkpoint另做两种无新训练的诊断：忽略stop head并强制R=d；忽略stop head并跑所有深度共用的预注册固定预算网格。同一权重、输入与答案读出，只有停止方式改变。两种诊断都不能代替自主停止主指标：

- 固定预算准确、主动停止错误：支持停止策略存在问题。
- 固定预算和主动停止都差：尚无证据表明执行能力已学会。
- T接近d、答案仍错：数轮数不等于执行组合。
- T接近d、答案正确：仍需中间状态探测和因果干预，才能支持一轮一跳机制。

组间D成功、H失败本身不能独立证明停止头失败，因为训练轨迹也不同；必须结合上述同一H权重的诊断。H若用少于或多于d轮主动停下并答对，仍算自主组合成功，另行判断是否支持一轮一跳。

固定预算诊断结果不能替代主指标；不得为每道测试题事后选正确轮数并算作自主成功。d2伙伴划分仍须严格留出，学习停止不解决已有k1伙伴捷径的可辨识性问题。

如希望证明学习到通用完成判断，应进一步干预中间状态，检验stop head是否跟随计算进展变化，而非仅依赖输入长度或循环计数。这些干预用于诊断，不在主评估中向模型注入正确状态。

## 5. 预期与理论边界

当前只见过原子+d2，学习停止可能表现为始终第1/2轮停、先按长度猜预算，或始终不停止。不能预先承诺泛化到更深。学习停止和学习可复用原子转移是两个需要共同解决的问题。

主候选目标仅奖励正确答案及较低计算量，并不强制T=d。一轮4层stack可以完成多步；若确实学到高效并行组合，它可能正确地使用少于d轮。用户提出的“一轮一次原子操作”作为待验证机制单独报告。

任意有限深度的理论论证还需要通用状态表示、对所有可达状态正确且可重复应用的原子转移、正确的内部关系选择及完成判定。有限d128测试通过不能单独证明d无限泛化。
