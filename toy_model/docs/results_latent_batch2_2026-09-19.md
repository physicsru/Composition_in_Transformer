# 第五批结果：自主 latent 执行 20 runs（设置与数字）

日期：2026-09-19。方案：[experiments_latent_batch2_20runs.md](experiments_latent_batch2_20runs.md)；实现、十项检查与偏差：[experiments_latent_batch2_log.md](experiments_latent_batch2_log.md)。本文把每个条件**到底是什么设置**和**得到什么数字**写清楚。

## 1. 一句话结论

20 个 run 全部完成，没有一个通过预注册的第一道门槛：**训练过的 20 个关系对拟合到 0.99–1.00，未见关系对的 d2 在全部 20 个 run 上都是 chance（0.001–0.003，1/500 = 0.002），d3–d128 同样是 chance**，不论条件（A / B / C / D / E / F）、不论内部预算（T = 1、8、256）。实体监督、读取监督、两者一起、多轮循环、不共享的 8 份 core，对未见关系对的效应全部是 0.000。模型把 10,000 条 d2 来源行记成了 `(起点, 关系对) → 答案` 的查表。读取监督确实把"第 1 轮读 r1、第 2 轮读 r2、之后读 EOP"迁移到了未见关系对（命中 0.6–1.0），但答案仍是 chance——**瓶颈不在读取地址，而在 latent 状态里没有可重组的"第一跳结果"**。

## 2. 共同设置

| 项 | 设置 |
|---|---|
| 世界与训练题 | 与第三、四批相同的冻结数据 `data/chain_loop`：E = 500、R = 20 个随机置换、world seed 42；40,000 行 w2（每个事实 8 次、8 个不同伙伴）+ 10,000 行 d2（k = 1 关系图的 20 个有序关系对 × 全部 500 个起点）；没有单独的原子行，没有 d ≥ 3 |
| 验证 / 测试 | 20 个验证关系对 × 50 起点 = 1,000 道 d2、20 行新配对 w2；测试 8 个深度 {2, 3, 4, 8, 16, 32, 64, 128} × {all_seen, one_new, random} × 5,000 = 120,000 条链（与第四批同一批语义题）；每格前 500 题为监测 / 诊断子集，后 4,500 题为确认子集 |
| **输入协议（新）** | 完整程序一次性给出。固定 262 个逻辑位置 = 两个 TASK 区，每区 `[TASK, 起点实体, 128 个程序槽, EOP]`。w2：两区各一个关系；d2 与测试链：只用第一区（第二区整区屏蔽）。d 个关系保持原顺序，放进从 128 个槽里无放回抽取再排序的 d 个槽；空槽不参与任何 key softmax。训练布局每次呈现重新抽（独立 RNG，A–F 同 seed 同布局），验证 / 测试布局预先冻结（hash `610700e0a5cedd6b`）。没有 loop 编号、剩余步数或"当前槽位"标记 |
| **输出协议** | 只有最终答案：w2 → `e_a(x) e_b(z) END_ANSWER`，d2 / 测试 → `e_y END_ANSWER`。全词表 greedy，最多 4 token；严格计分（实体个数与 END 必须恰好正确），格式错误单列 |
| 词表 | 原 524 项 + `TASK EOP EMPTY ANSWER END_ANSWER` = 529 |
| **模型（新）** | 2 层双向 Encoder 把 packet 编码成记忆 M（每次求解只算一次、循环中不改写）→ 4 个 learned latent slot Z₀ → `Z_t = Core(Z_{t-1}, M)` 重复 T 次（core = 2 个 block：latent self-attn → 对完整 M 的 cross-attn → 4d GELU FFN，pre-LN，残差支路零初始化）→ 1 层因果 AnswerDecoder **只** cross-attend 最终 Z_T（读不到 M）。d = 256，2 头，RoPE base 100（M 用逻辑位置 0–261，latent 262–265，答案前缀从 266 起），dropout 0，fp32。5.14M 参数（Encoder 1.58M、core 2.11M、decoder 1.05M、embedding / 输出头各 0.135M、实体辅助头 0.129M） |
| 训练 | 250k updates：前 50k 每步 256 行 w2，后 200k 每步 128 w2 + 128 d2。AdamW lr 3e-4（warmup 100）、wd 0.1、betas (0.9, 0.999)、全局梯度范数裁剪 1.0；每个 update 独立抽 T ∈ {2, 4, 8}；全程反传、不截断。来源流、布局流、T 流各用独立 RNG，评估不碰训练流；每个张量按 `(seed, 参数名)` 初始化，所以同 seed 的 A–E 同名张量逐位相同 |
| 损失 | `L_ans` = 答案实体 token 的平均 CE + CE(END_ANSWER)，按来源行平均。辅助 loss 只在阶段二、只对 d2 行、各自权重 0.5、对该行的 T 轮取平均；阶段一完全不建辅助图（A–D 同 seed 在 50k 前参数逐位相同，已验证） |
| 评估预算（预注册） | 主读数 250k：A–D、F 用统一 T = 8；A–D 另报 T = 256；E 只有 T = 1；F 没有 T > 8。预算矩阵（前 500 题 / 格）：A–D T ∈ {1, …, 256}，F {1, 2, 4, 8}。240k / 245k / best 各在 500 题 / 格上复核。best 只用浅验证（w2 整行 + d2）选，且只在阶段一之后 |
| 计算 | 每个 run 独占一个 GH200 节点（项目 gj26），49–52 ms / update：A–D 3.3–3.6 h、F 3.6–3.7 h、E 1.3–1.4 h；final 评估约 130 s。解析估计的训练 FLOPs：A–D、F 2.18e16，E 8.9e15。20 个 run 合计约 64 node-hours |

## 4. 结果

### 4.1 主读数（250k final，全 5,000 题 / 格；one_new 与 random 取较低者）

| 条件（seed 数） | d2 训练对拟合（all_seen） | **d2 未见关系对** | d3 | d4 | d8 | d16–d128 |
|---|---|---|---|---|---|---|
| A，T = 8（4） | 0.997–0.999 | **0.002–0.003** | 0.001–0.003 | 0.001–0.002 | 0.001–0.002 | 0.001–0.002 |
| B，T = 8（3） | 0.994–0.999 | **0.001–0.002** | 0.001–0.002 | 0.001 | 0.001–0.003 | 0.001–0.002 |
| C，T = 8（3） | 0.995–0.999 | **0.002** | 0.002 | 0.001–0.002 | 0.001–0.002 | 0.000–0.002 |
| D，T = 8（4） | 0.996–1.000 | **0.002–0.003** | 0.001–0.002 | 0.001–0.002 | 0.001–0.002 | 0.001–0.002 |
| E，T = 1（3） | 0.998 | **0.001–0.002** | 0.001–0.002 | 0.001–0.002 | 0.001–0.002 | 0.000–0.002 |
| F，T = 8（3） | 0.996–0.999 | **0.002–0.003** | 0.001–0.003 | 0.001–0.002 | 0.001 | 0.000–0.002 |
| A–D，T = 256（14） | 见 4.3 | **0.000–0.003** | ≤ 0.003 | ≤ 0.002 | ≤ 0.002 | ≤ 0.003 |

确认子集（后 4,500 题）与全 5,000 题的数字一致；240k / 245k / best 三个检查点的 d2 未见对同样是 0.002–0.008。部分 run 在长程序上输出非法格式（A_s123 / C_s123 的 d128 0.57 / 0.73，E_s7 / E_s123 / F_s123 的 d128 1.00），其余格式错误 ≤ 0.03。

**预注册判据（§8.1）**：d2 门槛（未见对 ≥ 95%，至少 3 个 seed）——A 0 / 4、B 0 / 3、C 0 / 3、D 0 / 4、E 0 / 3、F 0 / 3；之后的 d3–d8、d16–d128 判据全部 0。

**因子效应（§8.2，配对 seed 1 / 7 / 123，T = 8，各深度）**：实体监督主效应、读取监督主效应、交互、A − E（多轮收益）、A − F（共享 vs 不共享）全部落在 ±0.001 之内，即 0。

### 4.2 学到的是什么：d2 行被当作查表记住

| 读数（250k，各 run 的范围） | A | B | C | D | E | F |
|---|---|---|---|---|---|---|
| d2 训练行拟合 | 0.998–1.000 | 0.988–1.000 | 0.998–1.000 | 0.997–1.000 | 0.998–1.000 | 0.999–1.000 |
| d2 验证（未见关系对，1,000 题） | 0.000–0.003 | 0.000–0.002 | 0.000–0.002 | 0.000–0.005 | 0.000–0.005 | 0.000–0.002 |
| w2 验证整行（已知事实的新配对，20 行） | 0.00 / 0.40 / 1.00 / 1.00 | 0.05 / 0.25 / 1.00 | 0.00 / 0.35 / 1.00 | 0.05 / 0.35 / 1.00 / 1.00 | 1.00 / 0.95 / 1.00 | 1.00 / 0.00 / 1.00 |
| **单任务原子题 `TASK e r EOP`（10,000 项，训练中从未出现的格式）** | 0.005–0.054 | 0.009–0.025 | 0.004–0.033 | 0.004–0.031 | 0.025–0.116 | 0.003–0.020 |

（w2 一行按 seed 1 / 7 / 123 [/ 2026] 的顺序。）

- 每条 d2 来源行在阶段二被呈现约 2,560 次；训练对 100% 拟合、未见对为 chance，是"按 `(起点, 关系对)` 记答案"的特征，而不是用 w2 学到的事实去组合。
- 即使 w2 验证整行 1.00 的 run，同一批事实放进单任务格式也只有 0.3%–12%：事实知识被绑在 w2 的 packet 格式里，与第一轮"只在固定宽 2 行里见过的事实无法以单任务形式回忆"一致。
- **w2 也会被背行**：循环模型（A–D）里 seed 1、7 的 w2 验证整行只有 0.00–0.40（第一问 0.95–1.00，第二问 0.00–0.40），训练 loss ≈ 0.1 而新配对验证 loss ≈ 9；seed 123 / 2026 在 25k / 50k updates 学会可重组的 w2。同 seed 的 A–D 共用阶段一，所以四个条件表现相同。单轮的 E 三个 seed 都学会了（0.95–1.00，30k–40k updates）；F 的 seed 7 也在背行。背行的 run 梯度裁剪触发率 0.94–0.99，学会的 run 0.54–0.69。

### 4.3 诊断读数（标注为诊断，不是可观测的执行轨迹）

**读取头与实体 probe，在未见关系对的 d2 验证题上，T = 8：**

| 条件 | 读取头命中 r₁（第 1 轮）/ r₂（第 2 轮）/ EOP（第 3 轮） | 实体 probe 命中 x₁（第 1 轮）/ x₂（第 2 轮） |
|---|---|---|
| C（读取监督） | s1 1.00 / 1.00 / 1.00；s7 0.97 / 0.97 / 1.00；s123 0.60 / 0.73 / 1.00 | 未训练 |
| D（两者） | s1 0.98 / 0.98 / 1.00；s7 0.95 / 0.95 / 1.00；s123 0.59 / 0.67 / 1.00；s2026 0.82 / 0.83 / 1.00 | 0.14–0.28 / 0.00–0.01 |
| B（实体监督） | 未训练（0.00–0.12） | 0.09–0.11 / 0.00 |
| A、E、F（无辅助） | 自发的读取头不按 r₁ → r₂ 走（0.00–0.49） | 未训练 |

读取监督把"按顺序读关系、读完看 EOP"的规则迁移到了从未一起出现过的关系对上（0.6–1.0），而答案仍是 chance；实体监督在训练对上教会的 x₁ / x₂ 到了未见对只剩 0.1–0.3 / 0。也就是说：**能读到对的关系，但 latent 里没有可迁移的第一跳结果**——x₁ = r₁(x) 只依赖 `(x, r₁)`，但 k = 1 的训练图里 r₁ 永远只和同一个 r₂ 同现，状态与关系对身份纠缠在一起。

**额外计算（T 从 8 加到 256）对已拟合训练对的影响：**

| 条件 | d2 训练对拟合，T = 8 → T = 256 |
|---|---|
| A | 0.997–0.999 → 0.919 / 0.949 / 0.999 / 0.991 |
| C | 0.995–0.999 → 0.827 / 0.918 / 0.998 |
| B | 0.994–0.999 → 0.363 / 0.712 / 0.954 |
| D | 0.996–1.000 → 0.126 / 0.550 / 0.660 / 0.613 |

没有任何深度因为加 T 被解锁；带实体监督的 B / D 反而在训练预算之外最不稳定（D 从 T = 32 起下降）——浅题上被监督出来的"完成态"不是不动点。

**布局与后缀：**

- 同一语义题换 4 种布局，答案完全一致的比例：d2 0.48–0.73，d8 0.22–0.55（d128 为密集布局，只有一种）。答案依赖关系落在哪个槽；紧凑布局下训练对拟合仍是 0.99–1.00，未见对仍是 chance。
- 只改后半段一个关系，答案随之改变的比例：d3 0.77–0.94，d8 0.62–0.86，d32 0.15–0.59，d128 0.01–0.27（E_s7 0.50）；两题同时答对 0。长程序上模型基本不使用靠后的关系。

## 5. 结论与边界

1. **按方案 §9 的解释表，这是"A–D 都仅 d2 成功"的分支，且更弱**：只有训练过的关系对成功，未见关系对的 d2 就已经是 chance，与第四批的 R 同型。此配方没有从浅执行迁移到深执行；**不证明所有 latent / loop 架构不可能**。
2. **辅助监督定位到的不是方案预想的两个瓶颈之一**：读取地址可以被教会并迁移到新关系对（C / D），实体状态在训练对上也能被教会（B / D），但两者都不改变未见对的答案。缺的是"第一跳结果以可被任意第二跳复用的形式存在于状态里"。
3. **共享循环、多轮、不共享深度之间没有任何差别**（A = E = F = chance）：在这份数据上，固定题目记忆 + latent 工作区的结构本身没有带来可重组性；增大 T 只会让已拟合的答案变差。
4. **与前四批一致的主线**：同一份 40k w2 + 10k d2，k = 1 的关系图下每个关系只有一个出伙伴，端到端的答案监督会把 d2 记成按关系对的查表；显式的中间实体输出（第三批的 B / C / D 协议、第四批的 RC）能让 d2 新对到 1.0，规范的局部接口（第四批的 L）能到任意深度，而把中间步骤留在 latent 里的三种尝试（A 协议、R、本批）都停在训练对。
5. 边界：单一世界（seed 42）、k = 1、d = 256 的 5M 模型、固定 250k；w2 在两个 seed 上被背行本身就是该配方的一个失败模式。本批没有改配方；任何补救（k > 1 的关系伙伴数、让单任务格式进训练、减少每行重复次数、dropout / 更强正则、把 latent 状态的实体监督也加在 w2 上等）都应另立实验。
