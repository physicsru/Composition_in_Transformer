## 1. 当前实验支持到哪里

### 1.1 P1：伙伴多样性带来超出角色覆盖率的迁移——强证据

对两跳题 `h,T,H → H(T(h))`，中间实体记作 `b=T(h)`。role-unseen 意味着事实 H(b) 从未作为第二跳受组合监督，但它在原子训练中已经出现。

独立遍历实际训练数据确认：

- k=1/2/4/8 各臂每个 H 均为 400 个第二跳覆盖事实、100 个严格未覆盖事实。
- 每个覆盖事实每 epoch 恰好 8 次，均训练 525 epoch，即累计 4,200 次曝光、200,550 次新增更新。
- 四臂每 epoch 均为 97,661 行、145,600 个监督答案；unique 组合实例数随 k 改变，这是伙伴处理本身。
- U 集角色曝光、保留伙伴违规、H→H 训练、标签错误均为 0。
- 四臂共享内容完全相同的 12,800 条 role-seen、3,200 条 role-unseen 新伙伴测试；其第一跳事实 16,000/16,000 已在第一跳训练中出现。

下表为报告的最后五个保存 checkpoint 均值，已用原始 `metrics.jsonl` 复算，单位为百分比：

| k | 新伙伴 role-unseen，seed 1 | seed 7 | seed 123 | 新伙伴 role-seen 范围 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1.66 | 11.25 | 15.12 | 19.95–55.34 |
| 2 | 47.33 | 43.77 | 37.78 | 95.46–98.46 |
| 4 | 64.59 | 69.67 | 63.18 | 99.54–99.91 |
| 8 | 75.20 | 76.49 | 77.39 | 99.94–99.99 |

这些评估点的 P1 `atomic_heldout` 均为 100%。所以可确认：**在当前世界和续训配方中，伙伴多样性提高了已知原子事实在未受监督计算角色中的调用能力；纯覆盖解释不充分。**

尚不能确认：收益在任意伙伴划分、新世界或无限训练预算下同样成立；模型已经获得任意输入、任意深度可调用的精确关系算子。

### 1.2 P2：零 H→H 演示的已覆盖事实重组——强行为证据

七个 RC 数据集的基础训练前缀与 F_long 的 72,061 行逐行相同。基础预训练、重放和新增角色行中 H→H 均为 0。

| both 臂，报告五保存点均值 | seed 1 | seed 7 | seed 123 |
| --- | ---: | ---: | ---: |
| 两角色事实均覆盖的 HH，N=20,476 | 79.09% | 85.22% | 90.41% |
| 至少一个角色事实未覆盖，N=11,524 | 1.09% | 2.44% | 2.81% |

none/first/second 的 HH 约为 0–2%。可以确认：**当前训练配方能把分别受监督的角色知识重组为没有直接示例的 H→H。**

不能写成“各角色分别可用就必然足够”。未触发原反证条件不是普遍充分性的证明；HT×TH 与 HH 的乘积比较是事后描述，尚无独立校准或成功事件独立性的保证。

### 1.3 两角色的迁移表现不对称——已观察到，原因待分辨

first4 未覆盖输入迁移为 6.87/2.06/2.48%；second k4 未覆盖 bridge 迁移为 64.59/69.67/63.18%。both 的第二跳未覆盖迁移又降到 1.76/8.54/9.26%。

| --- | ---: | ---: |
| epoch | 525 | 415 |
| 新增更新数 | 200,550 | 200,030 |
| 每 active-role 事实累计曝光 | 4,200 | 3,320 |
| 每角色通道占全体答案比例 | 17.58% | 14.95% |

### 1.4 P3：中间状态能因果控制下游输出——有限范围内成立

第一层 block-0 输出、r1 位置的自然状态替换会改变最终答案，使其跟随源 bridge 的语义。该位置看不到 r2 和最终答案，因此这不是在最终答案位置直接注入答案。

在当前已测切片中：first4 未覆盖第一跳题由 14/300 正确，提升为同 bridge 干预后的 900/900 次正确；both 的 HH 切片由 191/300 提升到 843/900 次。三源是同一 target 的重复干预，不是三倍独立题数。

可确认：存在可被干预、可在部分不同前缀间复用的中间接口。不能仅由整 residual 替换区分“bridge 没算出”“编码不兼容”“路由未接通”，也不能宣布唯一电路、完全上下文无关或精确算子。

## 2. 原记录需要更正的地方

### 2.1 随机原子源的解释

`patch_bridge.py` 的 `random_src` 从 `(x,T)` 的 r 位置取第一层状态，却把 `src_b` 写成 None，只统计原目标题是否仍正确。应补算 `b_src=T(x)`，检验 `prediction == r2(b_src)`。

从已保存逐例预测复算：

| 目标 | 跟随随机源语义答案 | 保持原题答案 |
| --- | ---: | ---: |
| F_long，TT | 897/900 | 1/900 |
| RC_k4，TT | 900/900 | 1/900 |
| RC_k4，rc2 role-seen | 822/900 | 1/900 |
| RC_k4，rc2 role-unseen | 834/900 | 1/900 |
| RC_first4，rc1 role-unseen | 898/900 | 4/900 |

因此应撤回“随机原子源使原目标准确率近零，说明原子状态不可被第二阶段读取”。对于相同前缀，严格因果网络的 `[x,T,answer]` 与 `[x,T,r2]` 在位置 1 的同层状态应相同。该一致性可用作实现检查。

随机源关系全部来自 T，不代表 H 的第一层状态也已可用。RC_k4 的随机 bridge 约 80% 已覆盖；应按源覆盖分层，不能将混合跟随率直接与纯未覆盖源池比较。

### 2.2 新 RC 的 patching 样本范围

脚本按文件顺序取每类型前 300 题，而 RC 测试按关系、伙伴和实体排序：

- k1/k4 的 rc2 seen 只有 1 个 H×1 个 T；unseen 只有 1 个 H×3 个 T。
- first4 的 rc1 只有 1 个 H。
- both 的 `hh_cov_both` 全部是 `(r6,r6)` 自组合。

这些结果应标为 seed 1 的指定切片。旧 F pilot 覆盖多个 H，不能替代新 RC 的跨 H 复现。N0 先补这一缺口。

### 2.3 评估时间口径

原提案是 180/185/190/195/200k updates；实际报告取末五保存点。P1 为 162,350–200,550，both 为 144,600–192,800。后者比单角色窗口更早，不能继续称为严格执行原预注册终点。

## 6. N2：匹配每角色与基础重放，检验联合训练效应

### 6.1 六臂、固定分母与精确更新数

这是一个新的内部匹配配方。它与旧 RC 的宽度混合配方不同，不能把新旧差异当作一个单因素处理。

每 update 固定共同 128 个 TT、64 个单原子答案，外加两个各 32 个答案的角色槽。主四臂如下；所有非零 CE 项都使用固定分母 **256**，inactive 槽梯度为 0，**不能按当步活跃答案数重新归一化，也不能用有梯度的 TT 补足**。

| 臂 | 槽 A，32题 | 槽 B，32题 | 非零监督答案/step |
| --- | --- | --- | ---: |
| none | 0 loss | 0 loss | 192 |
| first | first 流 A | 0 loss | 224 |
| second | 0 loss | second 流 B | 224 |
| both | first 流 A | second 流 B | 256 |
| first2x | first 流 A | first 流 B | 256 |
| second2x | second 流 A | second 流 B | 256 |

`L = (Σ128 TT CE + Σ64 atomic CE + Σactive role CE) / 256`。

inactive 槽可省略计算，或使用独立行并把 loss 置零；不得拼到 active 序列中。模型无跨样本归一化；固定逻辑流与 loss 系数保持共同监督项一致。两臂参数训练后当然会分化，不能宣称后续实际梯度数值相同。

该设计有意不匹配主四臂的非零答案总数。**both−second 的处理是添加 first 监督，同时保持 TT、atomic、second 的逐题流、权重及更新数不变。** 若改用 TT 补足，估计的就变成“替换 TT 为 first”，必须另建实验名，不能混用解释。两个 double 臂用于比较相同总 H 监督量下的角色身份差异。

### 6.2 数据、剂量、优化

- 固定原 world42、原 U/S 与原伙伴划分；每角色 k=4、400事实覆盖，U 无角色曝光，HH训练为0。
- 共同 TT 从冻结的原 40,000 条训练组合循环平衡取样；全部 10,000 条原子事实循环平衡取样。
- 每角色通道先按相同 (H,state) 清单调度，再循环分配四伙伴。100 updates 完成一次 3,200 个角色事实的曝光；每400 updates 每事实四伙伴各一次。A/B 是预先冻结的平衡流，double的额外通道不得改变原共享通道。
- 精确 **200,000 新增 updates**：单通道每角色事实 **2,000 次**；double对应角色4,000次；both每角色仍2,000次。基础 TT 总25,600,000答案、单原子总12,800,000答案，各臂完全一致。
- 初始化和模型/优化参数同 N1；只恢复权重，optimizer与warmup统一重置。
- 命名 `NEXT_P2_{none,first,second,both,first2x,second2x}_s{1,7,123}`，共18次续训。全部使用新目录；500-step功能smoke用独立目录，不参与模型选择。

### 6.3 主检验与解释边界

每5,000更新保存并评估，主终点固定180/185/190/195/200k五点均值，不剔除尖峰。

1. **迁移下降主检验**：both−second 的 `rc2_newpair_role_unseen`。若配对区间全低于−5pp，且配对原子能力与 TT 能力未同幅下降，支持“添加第一角色监督降低未覆盖第二角色迁移”；仍需机制分析区分表示、路由和优化原因。
2. **剂量对照**：second2x−second 衡量额外同角色监督；both−second2x 比较同总H监督但不同角色分配。若两个加量臂都下降，不能将现象专属归因于first；first2x对first用于对称诊断。
3. **重组读数**：穷举32,000 HH，按两角色的四覆盖格分别报告，并区分对角与非对角。主要是both的双覆盖HH对none/first/second；不能仅报告混合HH。
4. **行为充分性反证**：对每个双覆盖HH题 `(h,H1,H2)`，分别用H1第一角色的四个保留T构造 `h,H1,T`，用H2第二角色的四个保留T构造 `T^{-1}(b),T,H2`，其中 `b=H1(h)`。两组T不要求相同；每个HH分别平均各自四题，保留同一H、输入/bridge以及重复权重。若两类配对混合均≥95%，而HH比较低者至少低10pp，且配对区间排除0，则反驳该条件下的简单角色成功充分性。未触发不等于证明充分性，乘积只作描述。

每 seed 单独报告所有预定对比与区间；若要在多个对比中挑选“显著机制”，须作多重比较控制，不能把辅助对比升级为主检验。HH微平均与按关系/bridge宏平均分开，避免可变块大小使点估计和区间对应不同量。

### 6.4 必需的新实现

精确 `max_updates`、step-based保存、固定逻辑流、固定分母CE、训练流manifest、累计每事实监督计数和每step类别计数。每个microbatch累积CE总和后除256，只调用一次optimizer.step。训练前核对数据hash、零HH、U无曝光、测试不相交；训练后核对真实更新数、计数与checkpoint完整性。

## 7. N3：把接口假说推进为形成过程理论

当前最合适的工作命题是：**组合泛化要求原子知识在指定层与角色上形成下游可读接口；伙伴多样性促进跨上下文调用。** 原子题完整两层正确，不保证第一层已能提供bridge；这是角色不对称的候选解释。

下一步理论读数应区分：原子完整网络正确、bridge在早期层可解码、自然状态能被下游因果读取、未覆盖角色事实可迁移。这四个时刻不预设相等。

先用固定target/source重评已有时间线；记录原子ACC、TT/HH/role-unseen、same-source恢复、wrong-source跟随、伙伴敏感性。可解码性只作辅助，不能替代因果读取。是否某机制指标先出现，再预测泛化，应以预先冻结的出现阈值和独立run检验；不能在同一条曲线上事后挑阈值。

未来从头训练的预测检验需单独冻结：共同训练配方、固定更新预算、独立校准/验证run、新world种子、预测公式、baseline及失败判据。本批N1/N2仍从F_long续训，不能承担“从随机初始化为什么emerge”的全部结论。

RoPE仍为base100；目前没有位置编码消融。若要将阶段差异归因于RoPE，需要独立的匹配架构实验，不能从现有两层结果直接推出。
